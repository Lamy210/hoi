## 2. Phase 1：最小プレイ可能なゲーム（次）

**開始条件**: Phase 0完了（本書）。**範囲**: 世界地図・プロヴィンス・3〜5国家・時間進行/停止・国家/地域選択・部隊作成・部隊移動・宣戦布告・簡易戦闘・領域占領・簡易国家AI・セーブ/ロード。

Change構成（依存順）:

1. `phase1-simulation-clock` — clock・game-core基盤（tick・速度・コマンドキュー・RNG・スケジューラ）
2. `phase1-world-map-provinces` — 地図データ読込・描画・選択（MapLibre）
3. `phase1-country-scenario` — 国家定義・シナリオパックロード・シナリオ/国家選択UI
4. `phase1-military-combat-mvp` — 師団・移動・宣戦・戦闘・占領・簡易補給
5. `phase1-country-ai-mvp` — 週次AIループ・判断ログ
6. `phase1-save-system-mvp` — セーブ/ロード・IndexedDB・検証
7. `phase1-game-ui-minimal` — メイン画面・時間UI・最小パネル・ja/en・ショートカット

**受入条件**: docs/16（MVP受入条件）＋ docs/13 G1〜G4のうちG1・G2・G3（ティアS）。

## 3. Phase 2：軍事戦略

- 師団テンプレート編成・戦線・攻勢計画・補給本格化（ハブ・鉄道・容量）・装備生産・指揮官・地形効果・包囲/撤退/動員。
- Change想定: `phase2-fronts-logistics`、`phase2-equipment-production`、`phase2-terrain-weather`、`phase2-events-basic`（イベント機構）。
- **受入**: 戦線を切った攻勢が補給断絶で崩壊する検証シナリオが動くこと・ティアS〜M中間規模でのtick予算達成。

## 4. Phase 3：国家・経済運営

- 国家予算・資源・生産・建設・貿易・人口・政治（支持率・法律・政党）・技術研究。
- Change想定: `phase3-market-economy`、`phase3-population-labor`、`phase3-politics-laws`、`phase3-research-tree`、`phase3-construction`、`phase3-tutorial`。
- **受入**: 5軸スコアが計算され、軍事以外の経路（経済・技術・生活水準）でスコアを伸ばすプレイが成立すること。経済安定性テスト（docs/13 §4）合格。

## 5. Phase 4：高度な国家シミュレーション → Phase 5：拡張・公開

- Phase 4: 外交拡張（条約網・外交プレイ）・講和会議・国家方針・海軍・空軍・高度AI・歴史/現代シナリオ拡大（ティアM/L）。
- Phase 5: MOD対応・シナリオエディタ・リプレイ・多言語拡張・PWA・性能最適化・マルチ実現可能性調査。
- 各PhaseのChangeは開始時に proposal → tasks として起案する（本書は目的・順序のみを記録）。
