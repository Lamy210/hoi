## 1. 仮称とひとことで言うと

- **仮称: 「Orbis」（オルビス／ラテン語で「世界・地球」）**。作業名であり、出荷前に改名し得る（判断 D-001）。
- ひとことで: **「理由がすべて見える、決定論で動くブラウザ型グランドストラテジー」**。
- タグライン案: 「あなたが決めるのは方針。世界は、その理由で動く。」

## 2. ターゲットプレイヤー

| 層 | 説明 | 本作が提供する価値 |
| --- | --- | --- |
| 主対象 | Paradox系を「面白そうだが学習コストが高い」と感じた層 | 段階的開示UIと計算根拠ツールチップで、深いシステムを学習しながら遊べる |
| 副対象 | 兵站・経済・外交を主軸に遊びたい層（Vic3/Democracy系） | 戦争以外のプレイスタイルに明確な報酬構造（スコア化） |
| 副対象 | OSS・MOD文化の参加者（OpenRA/Freeciv/Unciv層） | データ駆動の完全なMOD拡張と、決定論による検証可能性 |
| 非対象 | 非同期長期マルチを求める層（CoN系） | シングルプレイヤー優先。マルチは後期の実現可能性調査に留める |

## 3. デザインピラー（全判断の判定基準）

1. **地図が主役** — すべての数値・状態は地図上の表示モードとして可視化できる（15モード）。
2. **理由の見えるシミュレーション** — あらゆる導出値は計算根拠（入力・係数・式）をツールチップで開示する。AIの行動理由も内部ログとして閲覧可能。
3. **段階的な深さ** — 初期UIは最小構成。システムは必要になった時にアンロックされる。チュートリアルは「仕様の一部」として設計する（後付けにしない）。
4. **データとMOD駆動** — 財・産業・技術・イベント・シナリオはすべてデータパック。エンジンは内容に無関心（1936年に半導体は出現しない）。
5. **決定論と再現性** — 同一シード＋同一コマンド列は同一結果。リプレイ・平衡性テスト・将来のマルチの土台。
6. **複数の勝ち筋** — 軍事・経済・外交・技術・国民生活の5軸を独立にスコア化し、征服以外の道を構造的に等価にする。

## 4. 複数プレイスタイルの成立条件（非戦プレイの構造化）

戦争以外の道が「妥協」ではなく「戦略」になるために、以下を明確に設計する。

- **国家スコアの5軸分解**: 軍事力・経済規模（GDP・貿易シェア）・外交的影響力（条約網・国際機関での支持）・技術水準・国民生活水準（平均生活水準×識字率×失業率逆数）。スコアは毎月末に算出され、グラフで履歴表示される。
- **報酬の相互依存**: 経済規模が軍事維持費の上限を決め、生活水準が徴兵・研究の実効力を決める等、5軸が相互に支え合う。ただし資源は競合する（軍事費↑ → 福祉↓ → 生活水準↓）ため、全軸最大化は不可能。
- **勝利条件の複数化**: シナリオごとに目標テンプレート（覇権/経済大国/技術覇権/ regionの安定化/存続）を選択可能。勝利判定はスコア軸の組合せでデータ駆動定義する。
- **測定可能な受け皿**: すべての軸はツールチップで計算根拠を開示する（ピラー2との整合）。

## 5. 差別化ポイント

1. **ブラウザ完結** — インストール不要、クライアント完結型。外部API依存ゼロ（データは事前収集・同梱）。
2. **決定論** — 乱数はシード付きPRNG（PCG32）、超越関数はシミュ内禁止＋テーブル化。リプレイとハッシュ照合による平衡性検証を標準装備。
3. **計算根拠の透明性** — 導出値のトレースAPIをエンジンの一次関心事とする（後付けのデバッグ表示ではない）。
4. **兵站を主役に** — 補給はグラフフロー問題として可視化・攻略対象化。ボトルネック（鉄道の隘路・港湾容量）が攻撃目標になる。
5. **現実データとの橋渡し** — Natural Earth・World Bank等のオープンデータから正規化・検証済みシナリオパックを生成するパイプラインを正式機能とする（ライセンス準拠、docs/12）。
6. **AIの判断記録** — 他国の行動は「なぜ」まで閲覧できる（開発者モード）。難易度は資源ボーナスではなく判断能力の差で表現する。

## 6. シナリオ方針

| シナリオ | 時代 | 規模 | 目的 |
| --- | --- | --- | --- |
| **現代・東アジア（MVP旗艦）** | 2026年 | 5国家・約120プロヴィンス | Phase 1〜3の開発基盤。実統計（World Bank 2023等）を同梱してデータパイプラインを検証する |
| **架空・テラノヴァ島大陸** | 架空 | 8国家・96プロヴィンス | コンテンツ非依存性の証明。バランス調整用の純粋なテストベッド |
| **歴史・1936年世界** | 1936年 | Phase 4〜 | 歴史シナリオ。財リストから半導体等が除外されることをデータ駆動で証明する |
| **現代・世界** | 2026年 | 最終目標（250国家・20kプロヴィンス） | Phase 4〜5の性能目標シナリオ |

- 財・産業・技術はシナリオデータで定義され、時代に応じた出現制御はエンジンではなく**シナリオの責務**とする（4.3節の要件）。
- 現実統計・推定値・バランス調整値は、パック内メタデータの `quality_flag`（real / estimated / balanced）で明確に区分する（docs/12）。

## 7. 命名・法務上の注意

- 仮称「Orbis」は既存商標・既存ゲームとの衝突を本調査では確認していない（未確認を明記）。出荷前の商標調査を実施事項とする（docs/15 リスクR-24）。
- 既存ゲームのコード・画像・音楽・文章は一切複製しない。本調査は公開文書に基づくメカニクスの学習のみに限定している。

## 8. スコープの宣言（このプロジェクトがやらないこと）

- 個人単位の人口シミュレーション（CK3型）— 地域集約モデルのみ。
- 都市内ビル単位の建設（CS型）— プロヴィンス単位の建物レベルのみ。
- 戦術画面（リアルタイム戦闘の直接操作）— 戦線指示と自動戦闘解決。
- 常時稼働サーバを必要とする機能（ランキング、マルチ）— 後期調査対象。
- 有料LLM APIの常時稼働利用 — 補助的用途（ビルド時文章生成）に限定。
