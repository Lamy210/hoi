## 2. 優先順位の決定根拠

1. **Phase 1の範囲はユーザー要求そのまま**: 地図・プロヴィンス・3〜5国家・時間進行・選択・部隊作成/移動・宣戦・簡易戦闘・占領・簡易AI・セーブ。それ以外はすべて後Phaseに回す。
2. **Must が失敗するとゲームが成立しない**: 決定論（T-04）・コマンド検証（T-03）・所有/支配分離（M-03）は、後Phaseの全機能の土台のため Phase 1 から仕様として存在させる。
3. **Should/Could は明示的に外す**: 例えば海軍（M-10）は Phase 4、リプレイ（T-05）は Phase 5。過剰設計を避け、Phase 1 に「戦争の面白さの最小核」だけを置く。

## 3. Phase間の依存サマリ

Phase 1 → Phase 2（戦線・補給は師団移動・戦闘の上に構築）→ Phase 3（経済は建物・人口を軍事と共有）→ Phase 4（外交・海空軍は全システムの安定後）→ Phase 5（MODはデータ駆動設計の検証として最後に安定化）。

詳細は docs/14（実装ロードマップ）と openspec/changes/ の実装順序を参照。
