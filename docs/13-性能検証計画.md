# 13. 性能検証計画

- 作成日: 2026-11-14
- 状態: 確定（Phase 0 成果物 14/18）
- 原則: **性能目標は実測に基づいて確定する。未計測の性能を保証しない。** 本書は計画と測定方法の定義であり、確定値は実測後に本書へ追記する。

## 1. 規模の段階（設計目標とMVP必須規模の区別）

| ティア | 国家 | プロヴィンス | ユニット | 用途 | 性能目標（初期仮説・実測で修正） |
|---|---|---|---|---|---|
| S（MVP） | 5 | ~120 | ~200 | Phase 1–2 | tick 中央値 <5ms、p99 <20ms |
| M | 50 | ~3,000 | ~20,000 | Phase 3–4 | tick 中央値 <15ms、p99 <40ms |
| L（最終設計目標） | 250 | 20,000 | 100,000 | Phase 4–5 | tick 中央値 <50ms、p99 <120ms（仮説） |

- ユーザー要件の「最大250国家・20,000プロヴィンス・100,000ユニット」は**最終設計目標**であり、MVPの必須規模ではない。
- ティアLが実測で届かない場合、①スケジュール分散の強化 ②WASM化 ③州のピクセル/タイル化（OpenFront方式）の順で対処を評価する。届かない規模は仕様上「未対応」と明記する（過大保証の禁止）。

## 2. ベンチマーク項目と測定方法

| 項目 | 測定方法 | ツール |
|---|---|---|
| Tick処理時間 | Node上でエンジンを直接実行（UIなし）。N=100,000 tick、システム別に計測区間を分離 | `@orbis/bench`（Vitest上でなく単独実行） |
| AI処理時間 | AI思考の国別累積時間・思考あたり平均ms | benchハーネス |
| 地図描画FPS | Playwright実測: 60秒間のrAF回数＋dirty更新回数。ズーム/パン/モード切替込み | Playwright trace |
| メモリ消費量 | Node: process.memoryUsage() ヒープ系列。ブラウザ: performance.measureUserAgentSpecificMemory（隔離コンテキスト時） | bench / Playwright |
| セーブサイズ・時間 | 30日ごと自動セーブのサイズと書込時間の分布 | bench |
| ロード時間 | version移行含む復元時間＋derivedCache再計算時間 | bench |
| 経路探索 | 10,000件バッチのA*実行時間（戦線ベースの一括パス） | bench |
| ゲーム速度変更 | ×8連続30分でtick遅延率（目標レートとの差分）を記録 | bench |

## 3. 更新制御の設計仮説（検証対象）

1. cadence分散（日/週/月）＋オフストリーム（docs/08 §3）
2. 戦争関与フィルタ（平時国家は戦闘・補給のdaily処理をスキップ）
3. dirtyフラグ（補給グラフ・国境データの再計算をイベント駆動に）
4. 差分スナップショット（UIへの送信を変更範囲のみに）
5. LOD（描画ジオメトリ3段階）

各仮説の効果は「無効化した場合との比較ベンチ」で定量化し、採用判断を記録する。

## 4. 発散・安定性テスト（性能と一体で実施）

- シード付き長期シミュレーション（現代シナリオで50年×20シード）を自動実行し、以下を検証: GDP/価格/人口の発散（上限フラグ付き指標のアラート）、負値検知（INV-4）、NaN/Infinity発生、AIの無限ループ（思考時間上限＋同一コマンド連発検知）。
- 経済パラメータ変更（±20%）で市場が復帰すること（安定域の確認）。

## 5. 測定結果の記録方法

- `docs/13-性能実測結果.md`（実測開始後に作成）に、日付・環境（CPU/メモリ/ブラウザ・Node版）・シード・結果表を記録。
- CI ではティアSの回帰ベンチのみ実行（tick中央値に15%以上の悪化で失敗）。
- リリース前にティアM/Lの実測値を本書の「確定値」セクションへ転記し、初めて公表値とする。

## 6. 初期の受入ゲート（Phase 1完了時点）

| ゲート | 基準 |
|---|---|
| G1 | ティアSで ×8 相当の進行が30分間、目標レートの90%以上を維持 |
| G2 | 地図描画が一般ハードウェア（統合GPU・4GB RAM相当）で60fps（ズーム/パン込み） |
| G3 | セーブ <3MB、セーブ/ロード各 <300ms（ティアS） |
| G4 | 50年シミュレーションで発散・NaN・無限ループなし（20シード） |

（このゲート自体が実測対象であり、達成できなければPhase 2へ進まず設計を見直す。）
