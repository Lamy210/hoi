# 16. MVP受入条件

- 作成日: 2026-11-14
- 状態: 確定（Phase 0 成果物 17/18）
- 対象: Phase 1「最小プレイ可能なゲーム」の完了判定。すべての条件はテスト可能な形で書く（Gherkin相当の受け皿は tests/ に実装）。

## 1. 機能受入シナリオ（Feature: 最小プレイ可能）

```gherkin
Feature: Phase 1 MVP

Scenario: ゲーム開始
  When プレイヤーがシナリオ「現代・東アジア」を選択する
  And 国家「日本」を選択する
  Then メイン画面に地図が表示され、5国家が政治モードで色分けされる
  And 日付が「2026-01-01」と表示される

Scenario: 時間操作
  When 速度「×4」を選択する
  Then 1秒あたり4日が進行する
  When Spaceキーを押す
  Then 進行が一時停止する

Scenario: 部隊作成と移動
  Given 首都に徴兵可能人力がある
  When 部隊作成コマンドを発行する
  Then 師団が作成される（org 100, strength 1.0）
  When 隣接する自国プロヴィンスへ移動命令を出す
  And 時間を進める
  Then 師団は移動時間の経過後に到着する

Scenario: 宣戦と戦闘
  When 隣接国へCBを伴わず宣戦する（安定度ペナルティを確認）
  Then 戦争が開始される
  And 師団を敵プロヴィンスへ移動させると戦闘が解決される
  And 損耗は地形・補給・装備・組織率の係数を含むトレースで表示される

Scenario: 占領
  Given 防衛軍がいない敵プロヴィンスを14日間支配した
  Then そのプロヴィンスのcontrollerが移転する
  And 地図上で占領色が表示される

Scenario: AIの自律行動
  When 時間を30日進める
  Then 各AI国家が週次でコマンドを発行している（判断ログで確認）
  And AI国家はコマンド経由のみで状態を変更している（チートなし原則）

Scenario: セーブ/ロード
  When セーブを実行する
  And ロードする
  Then 状態ハッシュがセーブ時点と一致する

Scenario: 再現性
  When 同一シード・同一コマンド列で2回シミュレーションする
  Then 全月末アンカーの状態ハッシュが一致する
```

## 2. 定量受入条件（docs/13 と接続）

| # | 条件 | 測定 |
|---|---|---|
| Q-1 | ティアS（5国家/120州/200ユニット）でtick中央値<5ms・p99<20ms | bench |
| Q-2 | ×8で30分進行、目標レート90%以上維持 | bench |
| Q-3 | 地図60fps（ズーム/パン/モード切替込み） | Playwright |
| Q-4 | セーブ<3MB・保存/読込各<300ms | bench |
| Q-5 | 50年×20シードで発散・NaN・無限ループゼロ | bench |
| Q-6 | リプレイ二重実行でハッシュ一致（全月末アンカー） | CI |
| Q-7 | セーブ/ロード往復でハッシュ一致 | CI |
| Q-8 | 不変条件プロパティテスト（INV-1〜8）が1,000ランダムシードで全通過 | CI（fast-check） |

## 3. 品質・運用受入条件

| # | 条件 |
|---|---|
| A-1 | `openspec validate --all --strict` がエラー・警告ゼロ |
| A-2 | ユニット/統合/プロパティ/E2Eの4種テストが存在し、CIで緑 |
| A-3 | 不正セーブ・不正シナリオを与えると「拒否理由を表示して」停止する（クラッシュしない） |
| A-4 | ja/en両言語でUIが完結（ハードコード文字列ゼロ＝CIで検出） |
| A-5 | トレースツールチップが戦闘・補給・税収で動作（計算根拠の開示） |
| A-6 | 色覚多様性: 政治モードの区別がパターン/アイコン併用でも成立する |
| A-7 | キーボードのみで「開始→進行→セーブ」が完結する |
| A-8 | ランタイムの外部ネットワーク要求がゼロ（DevToolsで確認、E2Eに組み込み） |
