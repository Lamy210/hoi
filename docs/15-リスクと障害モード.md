## 1. 障害モード（QA観点の要求対応表）

ユーザー要求の品質保証観点（§12）と対策の対応:

| 要求観点 | 対応 |
|---|---|
| 国家間の領土重複 | パイプライン検証（R-08）＋シナリオロード時の所有者一意性チェック |
| プロヴィンス隣接関係 | 対称性プロパティテスト（INV-5）＋パック検証 |
| 部隊移動の合法性 | コマンド検証（敵地直進禁止・海越え禁止等）＋E2E |
| 資源の不正生成 | 収支台帳突合（R-07） |
| 負の在庫 | INV-4プロパティテスト |
| 人口の不整合 | 総和検証（地域≤国、年齢区分合計=総人口） |
| 経済の発散 | 安定性テスト（docs/13 §4）＋clamp機構 |
| 戦闘結果の整合性 | ゴールデンテスト（同一入力→同一損耗）＋境界値テスト（org 0/100） |
| AIの無限ループ | R-15 |
| 外交状態の矛盾 | 条約の状態機械仕様（diplomacy-system spec）＋矛盾検知テスト（戦争中の不可侵条約解除強制等） |
| 補給経路の遮断 | 包囲シナリオテスト（遮断→供給0→崩壊の時間計測） |
| セーブ/ロード一致 | INV-8往復テスト |
| 同一シード再現 | リプレイ二重実行（R-01） |
| 不正MOD/セーブ処理 | R-12 |
| 大規模シナリオの性能劣化 | ティアLベンチ（R-03） |
