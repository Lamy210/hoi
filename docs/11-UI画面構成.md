## 2. メインゲーム画面のレイアウト

```text
┌────────────────────────────────────────────────────┐
│ トップバー: 国家・資金・政治力・安定度 |  日付 | 停止/×1..×8 │ ← 常時
├──────┬──────────────────────────────────┬──────────┤
│ 左:   │                                  │ 右:       │
│ 国家   │        世界地図 (全モード)         │ コンテキスト│
│ サマリ │        ホバー=即時ツールチップ      │ パネル    │
│ ・警告 │        選択=詳細トレース          │ (選択対象  │
│  フィ │                                  │  に応じ)   │
│ ード  │                                  │           │
├──────┴──────────────────────────────────┴──────────┤
│ ボトム: 地図モード切替(15) | 戦争状況 | 検索 | ショートカット │
└────────────────────────────────────────────────────┘
```

- 地図は画面の約70%を占める常駐レイヤー。パネルはオーバレイ（地図を閉じない）。
- 警告フィードは優先度（宣戦＞包囲＞補給断絶＞経済＞情報）でソート、重要度ごとに自動一時停止の可否を持つ。

## 3. 情報の段階的開示

- **レベル0（初期）**: 地図・時間・国家概要・軍事（最小）のみ。他のパネルはシステム解放時に出現。
- **レベル1**: 建設・経済・政治が解放（Phase 3機能と連動）。
- **レベル2**: 統計・兵站詳細・AI判断ログ（開発者モード）。
- 設定で「全開示」に変更可能。開示レベルはセーブに含める。

## 4. ツールチップ（計算根拠）

- ホバー: 対象の現在値＋主要因トップ3（例: 補給効率 0.62 = 距離 0.85 × 容量 0.73）。
- クリック（トレース要求）: 全 contributors（ラベル・値・式）を一覧表示し、各要因へドリルダウン可能。
- すべての導出値はエンジンの trace API を経由（docs/07 §6）。UI側の装飾計算は行わない（数値の単一の真実源はエンジン）。

## 5. 操作性要件

| 項目 | 設計 |
|---|---|
| 地図操作 | ドラッグ移動・ホイールズーム（LOD連動）・ダブルクリックでズーム・右クリック=命令コンテキストメニュー |
| キーボード | Space=一時停止、1–5=速度、M=モード巡回、Esc=閉じる、F=検索、標準的なスクリーンショット・セーブショートカット。一覧は設定に表示 |
| 数値の変化 | グラフ（統計パネル）＋delta表示（前日比色分け、緑/赤のみに依存しないアイコン併用） |
| 警告優先度 | 優先度×緊急度でフィード並び替え、既読化は手動＋自動（解消時） |
| 色覚多様性 | Okabe-Itoパレット＋パターン/アイコン冗長化＋「色覚モード」設定＋WCAG AA相当のコントラストチェックをCIテストに追加 |
| 多言語 | ja/en のキー形式ローカライズ（ICU MessageFormat）。日付・数値は `Intl` で整形（UIのみ、シミュには影響しない） |
| アクセシビリティ | キーボードのみでの主要操作完結・ARIAラベル・フォーカス順序 |

## 6. 地図モードの色設計（15モード）

各モードのカラーマップはデータ駆動定義（`mapModes.json`）: `{mode, valueField, colorScale, overlay}`。政治モードは国色、補給モードは二色発散（不足=警告色）、戦争状況は交戦側をパターンで区別。いずれもパターン冗長化を必須とする。
