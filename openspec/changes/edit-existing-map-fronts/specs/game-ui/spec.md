## ADDED Requirements

### Requirement: 既存戦線の州範囲を非破壊的に編集する
プレイヤーは地図上で所有する既存戦線を選択し、州を追加・除去してから更新を一度に確定できなければならない（SHALL）。編集をキャンセルした場合、ゲーム状態と既存戦線は変化してはならない（SHALL NOT）。

#### Scenario: 平時戦線を編集して作戦を維持する
- **WHEN** プレイヤーが平時の戦線を選び州範囲を編集して保存する
- **THEN** 戦線ID・師団割当・攻勢目標・スタンス・停止状態が維持され、州範囲とrevisionのみが更新される

#### Scenario: 編集の破棄
- **WHEN** プレイヤーが編集を始めて州を追加した後にキャンセルする
- **THEN** 元の州範囲のままで、エンジンへ更新コマンドを送信しない

### Requirement: 競合する編集中の変更を拒否する
`updateFrontProvinces`は更新前に指定戦線の所有権、州支配、revisionの一致を検証しなければならない（SHALL）。範囲は1〜256州で重複を許してはならない（SHALL NOT）。

#### Scenario: 古い前線情報による編集の上書き
- **WHEN** 編集中に別コマンドで戦線のrevisionが変わった状態で保存を試みる
- **THEN** 古い編集は拒否され、現行の戦線・師団割当・コマンド世代を変更しない

#### Scenario: 戦線範囲変更による旧AI命令の失効
- **WHEN** 戦線の範囲を更新してrevisionが進む
- **THEN** 旧revisionを持つfrontMoveは適用されず、既存の手動移動は維持される
