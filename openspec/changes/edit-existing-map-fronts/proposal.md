# 地図上で既存戦線の範囲を直接編集する

## Why
PR #51〜#53 で前線の作成・攻勢線指定・軍単位の紐づけは可能になったが、作成済みの戦線の州範囲を修正するには一度削除し再作成する必要があった。削除で師団割当・目標・停止状態を失う。

## Scope
- `updateFrontProvinces` コマンド。対象戦線の所有者・生存する相手国・所有する州・範囲1〜256・重複・整数を確定時再検証。対象戦線の`revision`を要求し、古い編集を拒否する。
- 範囲の更新のみを反映し、戦線ID・軍割当・目標・スタンス・上限・停止状態を不変にする。
- 世代を更新することで旧世代の`frontMove`を拒否し、コマンドと戦線AIの競合を防止。
- 戦線一覧から選んで現在の州集合をドラフトへ複製。クリック・矩形ドラッグ（追加/置換/除外）で編集し、保存まではゲーム状態を書き換えない。
- 選択した戦線の既存表示をドラフト表示へ切り替え、州の追加/削除数を事前プレビュー。
- 取消は一切命令を発行しない。空集合・変更なし・世代不一致は保存不可。
- セーブ形式v18を変更せず既存revisionをUIスナップショットに公開する。

## Non-goals
海岸線に沿った自由曲線描画、任意地点への中継攻勢矢印、国境をまたぐ自動軍配分。
