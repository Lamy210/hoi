# Combat system — reproducible garrison stress benchmark (delta)

## ADDED Requirements

### Requirement: 最大規模の駐屯配置計測を再現可能にする
開発者は、構成可能な反復回数で最大256師団・64指定防衛地点の駐屯計画を実行し、p50/p95所要時間と経路lookup・実検索・ヒット・到達不能の件数を取得できなければならない（SHALL）。同じ世界状態の計画結果が各反復で一致しなかった場合、計測を失敗としなければならない（SHALL）。

#### Scenario: 最大規模の計測
- **WHEN** 256師団と64防衛地点、2回の計測反復を指定する
- **THEN** 2つの分布条件で合法な計画を実行し、反復結果の一致と計測サンプルを出力する

#### Scenario: 出発州の異なる2分布
- **WHEN** stackedとdistributedのワークロードを実行する
- **THEN** 同一州からの重複経路が多い条件と、分散して重複の少ない条件で探索件数を比較できる

### Requirement: 計測は本編の状態と命令を変更しない
計測のためのキャッシュ統計はオプションであり、WorldState・セーブ形式・コマンド契約に永続フィールドを追加してはならない（SHALL NOT）。計画呼び出しは読取専用で、ワールドハッシュを変更してはならない（SHALL NOT）。防衛移動命令は最大4件の上限を守らなければならない（SHALL）。

#### Scenario: キャッシュ統計の整合性
- **WHEN** 計画内で同一出発州・目標の経路lookupを繰り返す
- **THEN** 実検索を1回に数え、残りをヒットとし、lookup件数は検索件数とヒット件数の合計になる

#### Scenario: 読み取り専用計測
- **WHEN** 同じ合成WorldStateで繰り返し計画を実行する
- **THEN** 移動命令を発行せず、WorldStateハッシュと計画結果が維持される

### Requirement: ベンチマークの適用範囲を明示する
計測結果には、元のシナリオパックの州グラフを利用した**合成配置**であり、実運用の国家支配・外交・天候・海軍輸送を網羅せず、共有CIのp95やGC依存のheapDeltaを性能保証・リーク検出として扱わない旨を明示しなければならない（SHALL）。

#### Scenario: 結果を報告する
- **WHEN** ベンチマークが成功し、開発者が結果を確認する
- **THEN** 処理時間の実測値と経路検索件数を区別し、本番SLOが検証済みであると誤認させない
