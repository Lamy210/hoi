# Combat system — on-demand garrison route diagnosis (delta)

## ADDED Requirements

### Requirement: 明示操作時の合法陸路診断
プレイヤーは所有する駐屯作戦ごとに、エンジンと同じ非敵対陸路探索条件を用いる読み取り専用の経路診断を開始できなければならない（SHALL）。診断は自動移動命令を発行せず、WorldStateやセーブデータを変更してはならない（SHALL NOT）。

#### Scenario: 合法な陸路の存在
- **WHEN** 移動可能な配属師団から自国の指定地点へ非敵対陸路が存在する
- **THEN** 候補師団と陸路の存在を表示する。ただし同時配備の成立は保証しない

#### Scenario: 陸路不通
- **WHEN** 移動可能な配属師団すべてについて合法な陸路が存在しない
- **THEN** 現時点の条件では陸路なしと表示する

### Requirement: 診断限界と命令の保護
診断時は作戦所有権を検証し、経路探索最大64回の上限を設けなければならない（SHALL）。上限までに未確認の地点を到達不能と判定してはならない（SHALL NOT）。`tick`・作戦`revision`が変わった古い結果を現行状態として表示してはならない（SHALL NOT）。

#### Scenario: 上限到達
- **WHEN** ある地点の全候補を調べる前に経路探索回数上限へ達した
- **THEN** その地点を未確認と表示し、経路なしと断言しない

#### Scenario: 他国の作戦
- **WHEN** プレイヤーが所有しない駐屯作戦の診断を要求する
- **THEN** Workerは要求を拒否し、他国作戦の内部情報を返さない

#### Scenario: 作戦変更後
- **WHEN** 診断後に作戦のrevisionまたはゲームtickが変わる
- **THEN** 古い診断結果を画面から除外する
