# Military system — progressive frontline advance

## ADDED Requirements

### Requirement: 戦線は占領した敵国領土へ段階的に前進する
戦線に属する生存中の師団が、元の対戦国の領有州を占領して敵国と陸上接触している場合、その州は実効戦線として扱われなければならない (SHALL)。元の描画済み戦線州は変更してはならない (SHALL NOT)。

#### Scenario: 占領した国境州からの追加攻撃
- **WHEN** 師団が元の戦線を越えて占領した対戦国領土で、新たな敵国州と接している
- **THEN** 戦線AIは元の戦線に戻さず、新たな接触州から合法な次の州へ攻勢命令を出せる

#### Scenario: 遠隔地の無関係な国境
- **WHEN** 所属師団のいない他国境や別戦争の敵州が存在する
- **THEN** その州を現在の戦線に自動追加しない

### Requirement: 無人州には架空の守備軍を生成しない
無防備な敵国州にいる敵の師団数が0なら、戦力評価で人工的な守備戦力を加えてはならない (SHALL NOT)。防衛側の実在師団があれば、その戦力を使う。

#### Scenario: 守備師団不在の州
- **WHEN** 前線の隣接敵国州が無人で、進攻可能な所属師団がいる
- **THEN** 架空の守備隊による攻勢見送りを起こさず、実際の移動命令の合法性を再検証する

### Requirement: 実効戦線表示と手動命令を保持する
UIは実効戦線の州と陸上境界リンクを描画しなければならない (SHALL)。手動固定または作戦停止中に自動攻勢命令を出してはならない (SHALL NOT)。

#### Scenario: プレイヤーが手動固定する
- **WHEN** 前進した国境州にいる師団を手動固定する
- **THEN** 実効境界表示は維持し、自動移動命令の登録は止まる

#### Scenario: 前線を停止する
- **WHEN** 戦線のpausedが有効
- **THEN** 実効戦線の変化があっても自動攻勢命令を登録しない
