## MODIFIED Requirements

### Requirement: 戦闘解決の決定論性
戦闘の損耗計算はシード派生ストリームを用い（SHALL）、同一の状態・シードに対して同一結果を返さなければならない（SHALL）。損耗計算には地形に加えて天候の係数が含まれなければならない（SHALL）。天候は「晴/雨/雪/嵐」の4種で週ごとにプロヴィンス単位で決定論的に決定され（SHALL）、攻撃側の天候係数は 晴=1.0・雨=0.92・雪=0.85・嵐=0.80、緯度40度以北の冬季は雪が0.75に強化されなければならない（SHALL）。前面幅は plains=10 / hills=6 / mountains=4 / urban=5 / forest=6 / desert=8 としなければならない（SHALL）。天候係数は戦闘力トレースに表示されなければならない（SHALL）。

#### Scenario: 同一バトルの再現
- **WHEN** 同一状態・同一シードでバトルを再解決する
- **THEN** 日次の損耗列が完全一致する

#### Scenario: 冬季の攻勢不利
- **WHEN** 緯度40度以北の州で冬季に雪が降っている
- **THEN** 攻撃側の戦闘力に0.75の天候係数が適用され、トレースに表示される
