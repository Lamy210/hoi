# 生産ライン計画UI（Phase 6A — Part 3）

## 目的
PR #36の永続化済み計画と検証付きコマンドを画面から操作できるようにする。

## 仕様
- 生産パネルにモデルID・年式、要求工場/実割当、優先度、稼働状態、モデル切替効率を表示。
- `createProductionLine`, `updateProductionLine`, `switchProductionModel`, `deleteProductionLine` コマンドのみで状態を変更。
- 未研究の装備モデルは選択不可。受理前にサーバー側でも再検証する。
- 旧生産比率のUIを維持し、**新ラインは計画のみで実生産には反映されない**と画面に明示する。
- 工場要求数は整数、優先度は0〜9、PendingCommands中は再送をブロックする。

## 非対象
生産台帳・実在庫・戦闘補充・旧比率廃止は後続PR。UIは設定操作と予測表示のみ。
