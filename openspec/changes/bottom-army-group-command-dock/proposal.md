# 下部軍団・軍集団指揮ドック（HOI4型操作）

## Background
軍団/軍集団は従来右サイドバーの展開操作から作成・編入できたが、毎回名前を入力し、作成・編入・改名が複数の画面・コマンドに分かれていた。戦線の均等・戦略・最寄り配置や攻勢目標の地図指定もすでに実装されているが、発見しづらい。

## Scope
- マップ下部の常設指揮ドックに、軍団・軍集団カード、師団数と軍団数、選択、作成、改名のショートカットを追加する。
- 作成コマンドのnameを省略可能にする。省略時は所有国内の既存名を見て `軍団1`、`軍団2` または `軍集団1`、`軍集団2` を決定論的に選ぶ。明示name指定済みの旧クライアントとAIを維持する。
- `createArmy`で`unitIds`、`createArmyGroup`で`armyIds`を任意指定。全体事前検証後に形成と編入を一コマンドで行う。不正/外国/重複/上限超過ならカウンタを更新せず拒否する。
- `renameFormation`を追加。対象種別army/group、id、自国権限、名称妥当性を検証して名前だけ更新する。既存の保存形式v20とhashを使用する。
- 下部ドックから、選択/フォーカス中の師団の`deployToFront`（均等/戦略/最寄り）、前線作成、選択前線への攻勢目標地図ドラフト、防衛姿勢へ切り替えを再利用。
- 手動固定/移動/交戦/包囲中の師団にはワンクリック自動配置を発行せず、明示解除を求める。

## Non-goals
- 軍団ポートレートや指揮官画像、画面ドラッグ&ドロップ、兵站/艦隊/港の新規シミュレーションは別PR。
- 既存戦線AIの命令権限・乱数・セーブデータ形式は変更しない。
- 強襲上陸/海上補給を既存`moveUnits`に迂回実装しない（港湾/海域/船団の検証と新しい移動の状態機械が必要）。

## Validation
- 旧式の名前付き作成コマンドの挙動維持
- 同時編入のatomicity/foreign issuer/上限・セーブ復元・決定論
- 画面下部のドック表示、作成、改名、所属情報
- TypeScript, Vitest, Vite build, Playwright, OpenSpec strict, PR CI
