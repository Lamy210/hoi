# Game UI — bottom command dock

## ADDED Requirements

### Requirement: 下部の軍団・軍集団操作
画面下部の常設バーに、所有中の軍団・軍集団の名前と所属数、作成・選択・改名操作を表示しなければならない（SHALL）。

#### Scenario: 選択師団から軍団を作る
- **WHEN** プレイヤーが複数師団を選択して下部の軍団作成を押す
- **THEN** 名前入力なしで連番の軍団を一件作成し、選択師団を同時編入する

#### Scenario: 軍団から軍集団を作る
- **WHEN** どの軍集団にも属さない軍団をフォーカスして軍集団作成を押す
- **THEN** 連番の軍集団が作成され、フォーカスした軍団を同時編入する

### Requirement: 編成名の変更
軍団・軍集団は作成後に有効な名前へ変更できなければならず、変更はセーブ後も保持されなければならない（SHALL）。

#### Scenario: 名前の変更
- **WHEN** 所有する軍集団の名前を変更して保存・再開する
- **THEN** 指定名が保存され、軍集団と構成軍団の紐づけが変わらない

### Requirement: 既存戦線操作への到達
同じ下部バーから、地図戦線指定、均等/戦略/最寄りの自動前線配置、指定前線への攻勢目標線編集、防衛姿勢への切替に到達できなければならない（SHALL）。

#### Scenario: 前線へ師団を配置
- **WHEN** 所属する有効師団が移動中/包囲中/交戦中/手動固定中ではなく、操作対象の戦線を選ぶ
- **THEN** 既存の`deployToFront`を発行し、経路検証を保って自動配置する

#### Scenario: 手動固定が残る
- **WHEN** 操作対象に手動固定が残る師団が一件でも含まれる
- **THEN** 下部バーから自動配置コマンドを送らず、明示解除を案内する
