# Combat system — garrison defense orders

## ADDED Requirements

### Requirement: 駐屯命令は敵国境ではない地点も防衛できる
プレイヤーは自国支配下の1～64州と、指定した1～256師団に対して持続的な防衛作戦を作成できなければならない（SHALL）。作戦は前線`Front`の攻勢命令とは独立し、移動先は当該守備地点に限らなければならない（SHALL）。

#### Scenario: 防衛目標と師団
- **WHEN** 自国支配の離れた州を指定して非交戦の師団を駐屯させる
- **THEN** 合法な陸路を選んで移動を開始し、到着後は目標州に留まる

### Requirement: 手動命令と守備隊維持
駐屯AIは手動固定、移動中、包囲中、現在交戦中の師団を再配置してはならず（SHALL NOT）、守備済み州から最後の1師団を引き抜いて別の州を守らせてはならない（SHALL NOT）。

#### Scenario: 守備地点が2州で師団が1つ
- **WHEN** 単一師団が指定地点の片方に配置済みである
- **THEN** もう一方を無理に守らせるため移動させない

### Requirement: 自動命令は再検証する
駐屯AIが発行した移動命令は、適用時に作戦所有者・revision・停止状態・対象師団・経路・支配権を再検証しなければならない（SHALL）。

#### Scenario: 停止直後に保留された移動
- **WHEN** 駐屯AI移動を予約してからその作戦を停止する
- **THEN** 待機中の旧移動命令は拒否される
