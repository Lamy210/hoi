# Game UI — selected province defense orders

## ADDED Requirements

### Requirement: 下部指揮バーから任意の支配州を指定して駐屯を作る
画面下部の軍団操作バーは自国支配州の複数指定と選択中の師団/軍団/軍集団からの防衛作戦作成を可能にしなければならない（SHALL）。対象数や任務の二重割当、未選択は確認画面で無効化しなければならない（SHALL）。

#### Scenario: 指揮バーによる州防衛
- **WHEN** プレイヤーが州を選び師団を割り当てて防衛作戦を作る
- **THEN** 新しい作戦の対象州、師団数、停止状態が確認できる

### Requirement: 駐屯作戦の停止・再開・削除
既存の駐屯作戦を停止・再開・解除できなければならず、他国の作戦に操作を発行してはならない（SHALL NOT）。

#### Scenario: 作戦停止
- **WHEN** 作戦を停止した
- **THEN** 以降の駐屯AI移動命令が発行されない
