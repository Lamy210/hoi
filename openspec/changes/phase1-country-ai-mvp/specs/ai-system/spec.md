# Spec Delta

## ADDED Requirements

### Requirement: 週次思考ループの実装
AIは各国家を週次で思考し（SHALL）、思考順は国家ID順で固定し（SHALL）、思考時間上限を超えたモジュールはスキップして次週に繰り延べなければならない（SHALL）。

#### Scenario: 思考時間の上限
- **WHEN** 某国家の軍事AIが思考時間上限を超える
- **THEN** そのモジュールはスキップされ、判断ログに繰延が記録される

### Requirement: 軍事AIの戦線割当
軍事AIは影響力マップ（国境近接の敵軍力）に基づき師団を戦線へ割り当て（SHALL）、攻勢の発動判断はutility（敵戦力比・補給状態）で決定しなければならない（SHALL）。

#### Scenario: 開戦国への割当
- **WHEN** AI国家が戦争状態になる
- **THEN** 該当国境の戦線に師団が割り当てられる

### Requirement: 判断ログの記録実装
各思考の「モジュール・選択肢・スコア・選択理由」が国家ごとのリングバッファに記録され（SHALL）、照会APIで時系列に取得できなければならない（SHALL）。

#### Scenario: 宣戦判断の照会
- **WHEN** 開発者モードで宣戦判断を照会する
- **THEN** utilityのスコアと理由（CB・脅威・関係値）が表示される

### Requirement: 国家分散スケジュールの実装
AI思考は国家ID % 7 で週内に分散され（SHALL）、同一tickに思考する国家数は上限（既定：国家数の1/7相当）を超えない（SHALL NOT）。

#### Scenario: 分散の確認
- **WHEN** 250国家で7日を進める
- **THEN** 各tickの思考国家は約36国以下で、全国家が週内に思考する
