# 訓練予約・師団保有装備の型番追跡（Phase 6E）

## 目的
国家倉庫で識別した装備型番を、訓練への払い出し・訓練取消・配備・師団補充・戦闘損耗まで引き継ぐ。

## 前提と非機能
- `issuedEquipment: {holder: 'training'|'unit',holderId,modelId,quantity}[]` は
  既存訓練予約/師団装備の **識別可能な部分集合** であり、装備を追加生成しない。
- `Σ issuedEquipment(holder,category) <= 実予約/師団保有装備数量` を維持。
- 初期編成やv4〜v17の旧セーブ装備は未分類のまま。由来を推定しない。
- モデル別国家倉庫からの払い出しで、未分類を先に消費し、その後ID昇順に型番付き装備を払い出す。
- `startTraining` / `startCustomTraining` / キュー訓練で予約された識別済み数量を維持。
- キャンセルは旧国庫在庫へ全量返金し、識別済み分は元の型番で倉庫へ返却。
- 配備時は訓練予約の型番記録を、同一IDの師団へ移管（国庫在庫は変更しない）。
- 師団補充時は国庫から出た型番の識別を引き継ぎ、戦闘損耗では残装備数を超える記録を削除。
- 師団消滅時は全型番記録を破棄（返金しない）。
- 師団改編では残装備の上限を超えた型番記録を削除。差額で新調した装備は次段階まで型番未分類。
- **戦闘力の型番性能差はまだ有効化しない。** 装備型番は今は識別と整合の情報。

## セーブ・検証
- Save v18で型番予約/師団記録を保存、ハッシュへ追加。
- v4〜v17の旧セーブは以前のハッシュで検証し、型番予約/師団記録は空で移行。
- 不正な型番、重複、負数、存在しない予約/師団、未予約キューの記録、
  予約量/現有装備より大きい型番合計をロード時に拒否。
- ロード後の同期と決定論的継続、既存の全CIを維持。
