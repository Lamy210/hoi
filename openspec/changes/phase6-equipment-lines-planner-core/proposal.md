# Phase 6A — 生産ラインの決定論的プランナー

## 背景
現状は二財の配分率しかなく、モデル別のライン・工場効率・端数の扱いが必要。既存の `phase6-equipment-lines/design.md` を優先し、状態/在庫に影響しない計算ライブラリとして先行実装する。

## 今回のスコープ
- `ProductionLinePlan` 型を定義: country/id/modelId/requestedFactories/priority/efficiency/active。
- 1国の生産要求から整数工場を優先度降順/ID昇順で割当。過剰要求は維持し、実割当のみ縮退。
- 同型番は効率維持、同カテゴリ切替で半減(0.1〜0.5)、異カテゴリで0.1へリセット。
- 日次稼働時の効率上昇(+0.005、上限0.8)と、モデルID別の生産端数繰越を純関数化。
- 負数・重複ID・未知モデル・NaN等を拒否し、読み込み可能なカタログを利用する。

## 非スコープ／注意
- 本PRではゲーム状態への `productionLines` 導入、旧シェア配分の移行、生産工場の書き換え、型番別在庫、生産画面、実師団の補充は行わない。
- `modelDailyOutput` の基本日産は既存の2/1.2を用いた暫定計算。次PRで実シミュレーション接続時に正式に同定する。
- セーブ構造/状態ハッシュに変更はなく、既存の2財在庫の生産ルートへは接続していない。
- 全Phase6の受入要件達成を示すものではない。投資/AI/経済システムと装備台帳の統合は後続の段階に残る。
