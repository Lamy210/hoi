## ADDED Requirements

### Requirement: 公開版の命令操作と画面導線
プレイヤーは通常のUIで研究および戦争状況へ直接アクセスできなければならない（SHALL）。停止中に発行した命令は未実行件数を表示し、1日進行によるtick境界で反映できなければならない（SHALL）。命令の実行可否はエンジンに委ねる。

#### Scenario: 停止中の研究開始
- **WHEN** 停止状態で研究を選び、1日進める
- **THEN** 合法な研究は開始され、未実行件数が更新される

### Requirement: 実経過時間に応じた速度
速度1/2/4/8は経過時間を積算してtick要求を生成しなければならない（SHALL）。フレーム単位で最低1tickを強制してはならない（SHALL NOT）。Worker遅延時には過剰進行を防ぎ、性能警告を表示する。

#### Scenario: 一時停止と進行
- **WHEN** 停止してから速度4を選択する
- **THEN** tickは経過時間に応じて進み、停止中は自動tick要求が送信されない

### Requirement: 師団の現在地・選択と明示移動
通常UIは自国配備済み師団の現在州・状態・目的州を表示し、一覧と地図の州別カウンターで同じIDを選択できなければならない（SHALL）。一覧から現在地へ移動し、複数選択した師団の移動命令を一括発行できる。通常の州クリックで移動命令を暗黙発行してはならない（SHALL NOT）。右クリック、明示移動モード、または目的州選択によって命令する。停止中は未適用と現在地を区別し、適用された実経路と到着後の現在州を地図・一覧に反映する。

#### Scenario: 師団の現在地から目的州へ移動
- **WHEN** 一覧から自国師団を選択し、合法な目的州を明示して1日進める
- **THEN** 未適用中に現在地は変わらず、適用後の実経路または到着州が表示される

#### Scenario: 一括移動
- **WHEN** 自国師団を複数選択して合法な目的州を指示する
- **THEN** 選択IDを保持して1命令で移動し、移動状態を表示する

### Requirement: 明示攻撃と戦闘状況の表示
通常画面は自軍師団の選択から通常移動と攻撃を区別し、交戦中で選択した全師団が陸上で隣接する敵支配州のみを攻撃対象として提示しなければならない（SHALL）。右クリックは敵支配州に対して攻撃、それ以外は移動を指示する。宣戦は別の明示操作とし、攻撃クリックによって宣戦してはならない。攻撃の経路は隣接州への1区間とし、既存戦闘・占領解決に委ねる。敵師団数、戦闘中の状態、占領進捗を表示する。海峡越え攻撃、戦線/攻勢計画、継続的な命令種別の保持は後続Changeの範囲とする。

#### Scenario: 平時と交戦時の操作
- **WHEN** 平時に師団を選択し、宣戦後に合法な隣接敵州を指定する
- **THEN** 平時は攻撃を指示できず、交戦時は攻撃命令が登録され、日次処理で戦闘あるいは占領準備へ進む

#### Scenario: 一括攻撃の対象
- **WHEN** 選択師団の一部が対象州に隣接していない
- **THEN** 部分適用をせず命令を拒否する
