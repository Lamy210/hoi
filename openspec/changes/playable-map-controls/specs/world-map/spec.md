## ADDED Requirements

### Requirement: 北向きメルカトルカメラ
地図の投影はWeb Mercatorとし、北を上、東を右に表示しなければならない（SHALL）。Canvasの地物・ラベル・Pickingは同一のカメラ変換を使用し、ホイール/ボタン拡大縮小、ドラッグ移動、全体表示に対応しなければならない（SHALL）。ドラッグは州クリックとして扱ってはならない（SHALL NOT）。

#### Scenario: 拡大と移動
- **WHEN** プレイヤーが拡大・ホイール・ドラッグ操作を行う
- **THEN** 実際の地図描画が変化し、LOD切替後も州IDと描画座標が整合する

#### Scenario: 北向き表示
- **WHEN** 同じ経度の二つの地点を表示する
- **THEN** 緯度が高い地点は画面上方に置かれる

### Requirement: 州検索とカメラ移動
州名または州IDで検索し、ボタンまたはFキーで検索欄を開き、検索結果をクリックまたはEnterで選択できなければならない（SHALL）。選択時は地図カメラを該当州のラベル位置に移動する（SHALL）。高DPI環境でも描画位置とクリック判定が一致しなければならない（SHALL）。

#### Scenario: 検索して地図上で選択
- **WHEN** 州IDで検索して選択し、その州の表示位置をクリックする
- **THEN** 州の詳細を表示し、その州に対する合法な建設命令を発行できる
