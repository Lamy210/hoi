## ADDED Requirements

### Requirement: 北向きメルカトルカメラ
地図の投影はWeb Mercatorとし、北を上、東を右に表示しなければならない（SHALL）。Canvasの地物・ラベル・Pickingは同一のカメラ変換を使用し、ホイール/ボタン拡大縮小、ドラッグ移動、全体表示に対応しなければならない（SHALL）。ドラッグは州クリックとして扱ってはならない（SHALL NOT）。

#### Scenario: 拡大と移動
- **WHEN** プレイヤーが拡大・ホイール・ドラッグ操作を行う
- **THEN** 実際の地図描画が変化し、LOD切替後も州IDと描画座標が整合する

#### Scenario: 北向き表示
- **WHEN** 同じ経度の二つの地点を表示する
- **THEN** 緯度が高い地点は画面上方に置かれる
