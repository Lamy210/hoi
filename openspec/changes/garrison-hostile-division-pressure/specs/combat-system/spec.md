# Combat system — hostile division pressure for garrison targets (delta)

## ADDED Requirements

### Requirement: 駐屯地点への敵師団圧力の評価
交戦中の敵国が支配する隣接州にいる生存敵師団を観測し、その数を防衛優先度に反映しなければならない（SHALL）。敵に接している地点を非接敵地点より優先し、接敵地点内では隣接敵師団数、敵支配州との接触数、首都、沿岸、インフラ、人口、州IDで決定論的に比較しなければならない（SHALL）。

#### Scenario: 敵が同じ境界上の一方に集結
- **WHEN** 2地点の敵隣接州数は等しいが、一方にのみ敵師団が集まっている
- **THEN** 敵師団数が多い地点を先に検討する

#### Scenario: 中立軍や撃破済みの部隊
- **WHEN** 敵支配州に中立軍や撃破済みの師団が存在する
- **THEN** それらを敵師団圧力として数えない

#### Scenario: 戦争終結後の再計算
- **WHEN** 交戦が終了した状態で同じ世界を再評価する
- **THEN** 交戦中の敵師団数と敵隣接州数はゼロになる

### Requirement: 既存の指揮系統の安全性と説明可能性
脅威順位の評価はWorldStateを変更せず、保存形式・駐屯命令・既存の毎週4命令上限を変更してはならない（SHALL NOT）。戦闘中、移動中、包囲、手動固定、最後の守備隊の移動制限は維持しなければならない（SHALL）。診断UIには推定戦闘力ではなく観測した隣接敵師団数を表示しなければならない（SHALL）。

#### Scenario: 守備地点の最後の1師団
- **WHEN** 高順位の別地点があっても、現在守っている地点に最後の守備師団しかいない
- **THEN** その守備師団を強制移動させない

#### Scenario: セーブから復元した後
- **WHEN** 同じ世界状態をセーブから復元して順位を再評価する
- **THEN** 同じ順位を算出し、新たな永続フィールドに依存しない
