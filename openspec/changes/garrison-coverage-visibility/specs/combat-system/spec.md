# Combat system — garrison target coverage visibility (delta)

## ADDED Requirements

### Requirement: 駐屯対象地点の現在カバレッジ
指揮UIは各駐屯作戦の対象州を、現時点の師団位置と移動命令に基づいて「防衛中」「移動中」「未防衛」「支配喪失」に分類して表示しなければならない（SHALL）。観測情報のみを使い、実際の経路計算をせず到達不能を断定してはならない（SHALL NOT）。

#### Scenario: 現地守備と目的地へ移動中
- **WHEN** 対象州に停止中の守備師団があり、別の対象州へ所属師団が移動中
- **THEN** 前者を防衛中、後者を移動中とし、それ以外の地点を未防衛と表示する

#### Scenario: 他地点へ移動中の師団
- **WHEN** 師団が守備州に現在位置していても移動命令で別の州へ向かっている
- **THEN** 元の州は防衛中と誤表示せず、到着先のみを移動中と表示する

#### Scenario: 支配権喪失
- **WHEN** 防衛指定州が敵国の支配に変わった
- **THEN** 師団が残留していても支配喪失として表示し、通常の守備状態と区別する

### Requirement: 未防衛理由と投影の不変性
未防衛地点について、作戦停止、配属師団ゼロ、移動可能師団ゼロ、それ以外の作戦・経路未確認を区別しなければならない（SHALL）。表示処理はWorldState、命令、セーブ形式を変更してはならない（SHALL NOT）。

#### Scenario: 手動固定の配属師団のみ
- **WHEN** 配属師団がすべて手動固定・交戦中・包囲中または他地点へ移動中
- **THEN** 移動可能師団なしと表示するが、到達不能と断定しない

#### Scenario: 防衛状況を表示した後
- **WHEN** 指揮UIが防衛状況を投影する
- **THEN** 入力スナップショットと駐屯命令は変更されない
