# Phase8 港湾・指定地点の駐屯カバレッジ可視化

## Why
PR #89で登録済み港を駐屯作戦の対象に追加できるようになったが、作戦作成後の各港に守備隊がいるか、移動中か、未防衛かを指揮画面で判断できない。支配権喪失や手動固定などの理由も区別したい。

## What Changes
- UiSnapshotの既存師団位置、移動先、支配者、作戦の停止状態から駐屯地点別の状態を算出する読み取り専用投影を追加する。
- 「防衛中」「移動中」「未防衛」「支配喪失」を対象州ごとに表示し、作戦全体の集計も表示する。
- 未防衛の場合は停止中・配属師団なし・移動可能師団なし・作戦/経路確認待ちのうち観測できる理由のみを表示する。
- 到達不能はUIスナップショットだけでは確定できないため判定・断定しない。
- AIの移動ロジック、コマンド、セーブデータは変更しない。

## Capabilities
- Phase8の既存港・指定州防衛と駐屯作戦v21の状況をリアルタイムのUIスナップショットから可視化する。
- 同じ駐屯対象が重複した場合も投影を一意化し、師団所属の所有権を再確認する。

## Impact
- `src/ui/garrisonCoverage.ts` と `ArmyCommandDock.tsx` のみ動作変更。
- VitestおよびPlaywrightで状態判定と表示を検証。
- 新しい依存・ネットワーク接続・永続化なし。決定論的なゲームエンジンには影響しない。
