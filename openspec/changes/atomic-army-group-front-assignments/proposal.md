# 軍集団配下の複数軍を異なる戦線へ原子的に割り当てる

## Why
軍集団から複数の軍を選択・状態確認できるようになったが、異なる戦線へ割り当てるには軍ごとの逐次コマンドが必要で、途中の拒否で部分適用され得る。

## What Changes
- `assignGroupFronts` は `groupId` と、軍ID・戦線ID・戦線revision・現行所属師団IDを持つ複数（2〜5）エントリを一括検証する。
- 全件合法な場合のみ1つのプレイヤーコマンドで師団の `frontId` を変更する。失敗時はどの師団も変更しない。
- 軍集団所有権、軍の所属、現行の師団全員、戦線所有権・生存・revision、駐屯との排他、戦闘/包囲/移動状態を再検証する。
- 手動固定 `manualHold` と既存経路は変更しない。実際の移動は既存の `deployToFront` を別途実行する。
- 軍集団指揮画面から各軍の戦線を選択し、2軍以上を1回で割り当てる。

## Invariants / Non-goals
- `Unit.armyId -> Army.groupId` が唯一の指揮階層。割当計画を二重保存しない。
- WorldState/セーブ版や既存 `assignToFront` の挙動を変更しない。
- 戦線を軍ごとに自動最適化するAI、戦線上の州への物理移動、敵領土への攻撃は対象外。
- UIの事前判定は利便性のためで、最終認可はエンジンが行う。

## Risks
- 古いUIで軍所属または戦線revisionが更新されている可能性。入力した所属師団集合と現行集合を厳密照合する。
- 一括適用は上限5軍、256師団。パス探索を行わないため実行時間の増大を抑える。
