# 研究連動装備モデルカタログ (Issue #30 / 第1段階)

## 目的
既存の二財（歩兵装備・火砲）の生産保存則を変更せずに、今後の型番別生産・補充が参照する装備ID・年式・性能・解禁技術のデータを確定する。

## 契約
- シナリオパックの任意ファイル `equipment-models.json` に型番モデルを定義。
- カタログのID一意、カテゴリ/年式/性能値/名称、存在する研究IDへの参照をロード時にチェックする。
- チェックサム検証の単一バイト列を維持し、JSON検証済みデータをロードする。
- ゲーム側は「研究済み」のID集合を用いて設計解禁済みモデルを純粋計算する。
- 研究ツリーには解禁モデルと年式を表示する。
- 現行の装備在庫・生産量・戦闘係数への影響は **ない**。これはモデル/研究データの第一段階であり、製造機能ではない。

## 後続実装
- 国別・型式別在庫台帳、既存二財からの移行
- 工場の型番別配分、切替損失
- 訓練予約・師団配備・戦闘損耗・補充への型式の一貫適用
- バージョン付きセーブ移行と旧型在庫の資源保存の回帰
