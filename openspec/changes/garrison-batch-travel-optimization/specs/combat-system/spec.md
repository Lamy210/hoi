# Combat system — bounded garrison batch travel-time optimization (delta)

## ADDED Requirements

### Requirement: 駐屯バッチの最短合計移動時間
駐屯作戦は高優先順位の防衛地点を先に選び、合法に移動可能な師団を割り当てなければならない（SHALL）。選択された最大4件の移動計画に対して、同じ師団集合・同じ目的地集合のすべての合法な組み合わせから、移動条件・師団の速度に応じた予想移動日数の合計が最小になるものを採用しなければならない（SHALL）。改善しない場合は元の割当を保持しなければならない（SHALL）。

#### Scenario: 2港に2師団を配置
- **WHEN** 高優先港へ近い師団を先に割り当てると、別の師団が低優先港まで大きく迂回する
- **THEN** 同じ2港と同じ2師団を保ちながら、合計移動時間が短い割当へ変更する

#### Scenario: 3師団の複数配置
- **WHEN** 3地点に対して選択された3師団の合法な割当が複数ある
- **THEN** 最大6通りの割当のうち予想合計移動時間が最短のものを採用する

### Requirement: 経路合法性・守備保護・計算量の上限
代替の割当でも既存の合法な非敵対陸路探索を再実行しなければならない（SHALL）。目的地、出発する師団の集合、元の優先順位、最後の守備隊・手動固定・交戦・包囲・移動中の制約を変えてはならない（SHALL NOT）。週次4命令上限を超えてはならない（SHALL NOT）。

#### Scenario: 代替の陸路が存在しない
- **WHEN** 師団と目標の組み換えの一部で合法な陸路が存在しない
- **THEN** その割当を不採用にし、元の合法な割当を維持する

#### Scenario: 手動固定の師団
- **WHEN** 作戦の師団の一部に手動固定が設定されている
- **THEN** その師団を最適化のために移動可能な師団集合へ加えない

#### Scenario: セーブ復元後の再現
- **WHEN** 同じ状態から同じ駐屯計画を計算し、セーブ復元後にゲームを進める
- **THEN** 計画とハッシュが一致し、保存形式は変更されない
