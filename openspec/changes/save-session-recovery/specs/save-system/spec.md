## ADDED Requirements

### Requirement: 復元後の命令番号
ゲームロード成功後、Workerは復元したジャーナル内のプレイヤー命令番号と重複しない番号を発行しなければならない（SHALL）。

#### Scenario: ブラウザ再起動後の研究
- **WHEN** 研究を開始し、保存してブラウザを再読み込みし、セーブをロードする
- **THEN** 後続の合法な研究命令は番号重複によって拒否されない

### Requirement: 保存確定と未実行命令
IndexedDBの書き込み成功はトランザクション確定後に通知しなければならない（SHALL）。未実行プレイヤー命令を失わないよう、保存と復元はその命令を反映してから実行する（SHALL）。

#### Scenario: 停止中の保存
- **WHEN** 未実行命令を残して保存しようとする
- **THEN** 保存操作は抑止され、命令反映後に保存できる

#### Scenario: 書き込み失敗
- **WHEN** 保存トランザクションがabortされる
- **THEN** 成功扱いせず、失敗を利用者へ通知する
