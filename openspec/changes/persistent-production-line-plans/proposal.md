# 生産ライン計画状態の永続化（Phase 6A — Part 2）

## 背景
PR #35の工場配分・切替効率計算は純関数であり、ゲーム内の国家状態・保存・コマンドに接続されていなかった。

## 変更契約
- 新しいワールド状態に `productionLines[]` と `nextProductionLineId` を追加（v14）。
- v13以前のセーブでは従来の歩兵/火砲配分率から `floor(F*share)` と残余を計算し、既存の基礎モデル2件の計画を生成。既存の在庫・配分率・戦闘はそのまま復元。
- `createProductionLine`, `updateProductionLine`, `switchProductionModel`, `deleteProductionLine` を導入。研究完了前の新型モデルは作成/切替拒否。他国ラインも拒否。
- 配分プランは決定論的な状態ハッシュとセーブに含める。新旧バージョンでハッシュ適用範囲を分離し、既存セーブを失効させない。
- v14のロード時はラインの所有・ID・型番・工場要求・効率・優先度・上限を検証し、不正入力を非破壊で拒否。

## 非対象／重要
- 生産ラインは **計画状態** であり、歩兵装備と火砲の実在庫は依然 `productionShare` で生産される。研究済みモデルをラインに割り当てただけでは実在庫や師団装備へ反映しない。
- 端数繰越台帳・実生産の切替・訓練予約・補充の型式別保存則は次の変更へ分割する。
- UIの編集画面は後続の独立PRで追加する。
