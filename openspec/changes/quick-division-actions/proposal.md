# 師団選択後のクイック操作バー

## 背景
指揮系統ツリーで師団を選んだ後、移動・攻撃ボタンが長い一覧の下部にあり、操作が煩雑だった。

## 仕様
- 指揮系統と詳細一覧で選択した師団が1件以上ある場合、右パネルの上部に即時操作バーを表示
- 移動、攻撃、停止・待機、戦線割当パネル、地図上の位置へフォーカス、選択解除に対応
- 既存の操作ボタンと同じハンドラと可否判定を使う。移動・攻撃は排他的モード
- 選択解除は移動/攻撃モードを終え、目的地入力も初期化
- 既存の下部ボタンは残し、キーボード/E2E/API互換を維持
- スクロール時も操作バーを見つけやすい配置にし、狭い画面では2列にする

## テスト
- 師団未選択では非表示、選択時に表示
- 移動のトグルが既存操作と同期
- 停止・待機をコマンド経由で発行、選択解除で復元
- 全既存PlaywrightとVitestの回帰
