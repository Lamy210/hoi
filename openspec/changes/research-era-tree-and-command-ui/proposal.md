# 研究ツリーと師団管理UIの改善

## 目的
現代東アジアシナリオを対象に、研究を分野・前提・年式のツリーへ移行し、陸軍編成の変更操作を短縮する。研究力、国別状態、セーブ形式、戦闘力計算、決定論を維持する。

## スコープ
- 銃器・砲兵・無人機・ドクトリン・工業・兵站の技術を追加し、前提依存関係を表示する。
- 技術の任意の年式により先行研究ペナルティ（1〜4倍）を日次計算。開始禁止にはしない。
- 歩兵攻撃・歩兵防御・砲兵攻撃技術の効果を戦闘係数に反映する。砲兵効果は砲兵装備充足率に比例する。
- 軍団一覧をタイル化し、1師団の保存済み自由編成への改編を既存の検証付きコマンドで行う。
- 既存シナリオの年式・名称が欠落していても研究できる。

## 非スコープ
- 銃/車両ごとの装備在庫分離や火器型番別生産ライン、航空戦の新規シミュレーション。
- 複数師団の非原子的な連続改編（資源の途中不足で半端に適用されるため別タスク）。
- 固有国家の歴史的技術優劣（現状の技術年式・倍率はゲームバランス用の仮値）。

## 安全性と互換性
- パック JSON の SHA-256 を同時更新し検証付きのロードを維持する。
- 保存済みの研究状態は技術 ID・進捗のみなので構造変更は不要。
- 未修得技術を既に保存された研究進行に追加しても技術効果は後方適用されない。
- 年代倍率は毎日再計算するので、経年で進捗が自然に加速する。
- 新しい技術名・カテゴリ・性能値は実在史実を認定するものではなく、ゲーム内の調整値。
