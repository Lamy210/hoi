# Save system — v20 combat readiness

## ADDED Requirements

### Requirement: 戦闘準備状態の保存と旧形式互換
v20セーブは塹壕化0..6と攻勢準備0..5を保持・検証し、全決定論ハッシュへ含めなければならない (SHALL)。旧v19以前のセーブでは追加フィールドなしを許容し、ハッシュを旧実装と一致させなければならない (SHALL)。

#### Scenario: v20保存・ロード・継続プレイ
- **WHEN** 塹壕化・攻勢準備を蓄積したゲームを保存して再読み込みする
- **THEN** 全値・ハッシュが復元され、同じ日数の再生も一致する

#### Scenario: 不正な準備値
- **WHEN** 保存値が上限超過、負数、非整数、非数値に改ざんされる
- **THEN** ローダーは形式違反を返し、部分的な復元を公開しない

#### Scenario: 旧v19保存
- **WHEN** v19の正規保存を読み込む
- **THEN** 新しい塹壕化・準備値を未設定0として扱い、歴史的なv19ハッシュを使って整合性を検証する
