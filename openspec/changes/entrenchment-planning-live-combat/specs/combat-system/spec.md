# Combat system — entrenchment and offensive planning

## ADDED Requirements

### Requirement: 静止中の塹壕化
自国支配州に静止して非交戦かつ一定以上の補給を受ける師団は、塹壕化を日次で蓄積しなければならない (SHALL)。0から6までの整数とし、移動・退却・包囲・敵支配州では塹壕化を失わなければならない (SHALL)。

#### Scenario: 高補給の守備師団
- **WHEN** 自軍支配州に師団が6日間静止し交戦しない
- **THEN** 塹壕化6となり防御戦力が最大1.30倍となる

#### Scenario: 移動と退却
- **WHEN** 師団が実移動・退却で州を移るか移動中になる
- **THEN** 次の戦闘日までに塹壕化が0になる

#### Scenario: 戦闘中の塹壕
- **WHEN** 守備師団が同じ州で戦い続ける
- **THEN** 既存の塹壕化を防御に用いるが、新たな塹壕を積み増さない

### Requirement: 攻勢準備の蓄積と消費
攻勢または限定反撃の非停止戦線に属する、組織率60以上で十分に補給された非交戦師団には、日次で攻勢準備が蓄積されなければならない (SHALL)。準備は最大5、攻撃倍率は最大1.20倍で、移動や戦闘で減衰しなければならない (SHALL)。

#### Scenario: 作戦準備済み師団の進軍
- **WHEN** 攻勢/反撃戦線の師団が5日間待機して準備した後に移動を開始する
- **THEN** 進軍中は1日につき準備が1減り、残存分の補正が初戦で有効になる

#### Scenario: 作戦の停止
- **WHEN** 前線を停止または手動固定し、新たな準備条件を満たさない
- **THEN** 攻勢準備を新たに獲得せず、日次で減衰する

### Requirement: 決定論・補正トレース
塹壕化と攻勢準備の係数は、既存の実戦闘評価とユニットトレースに同じ数値として反映しなければならない (SHALL)。

#### Scenario: 同一条件の塹壕比較
- **WHEN** 同じシード・師団・戦場で防衛側の塹壕化を0から6に変える
- **THEN** 準備済み防衛側の組織率損耗が少なくなる
