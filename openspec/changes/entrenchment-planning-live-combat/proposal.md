# 塹壕化・攻勢準備を実戦闘へ接続（保存v20）

## 背景
限定反撃、組織率再編、前線の動的追従は実装済みだが、静止した守備師団の陣地構築と攻勢計画の事前準備が実戦闘力に反映されていない。このため守勢が単純な師団数に依存し、一進一退の戦略選択が乏しい。

## 変更
- 永続的かつ決定論的な師団別整数値 `entrenchment?:0..6` と `preparation?:0..5` を追加。未設定は0。
- 日次の移動・戦闘・占領・補充後に更新。自国支配州で静止・非交戦かつ補給効率0.35以上なら塹壕化+1/日（上限6）。低補給では減衰。移動・退却・包囲・敵支配州では塹壕を失う。
- 攻勢/限定反撃戦線に所属し、未停止・交戦中・非手動固定・補給0.35以上・組織率60以上の師団は攻勢準備+1/日（上限5）。停止/手動固定/平和/低補給で減衰。移動・戦闘は-1/日、移動後も残存分を初戦で使用できる。
- 防衛戦闘係数 `1+0.05*entrenchment`、攻撃係数 `1+0.04*preparation`。計算とtraceは共通のpure関数を使用し、元の装備・指揮官・天候補正を維持。
- スナップショットおよび師団画面に値と補正を表示。
- 保存形式v20で追加値を検証し、状態ハッシュに追加。旧v4〜19のハッシュは既存と同じ値で検証する。旧v19を読み込んだ後は未設定値を0として扱う。

## 非目標
HOI4の厳密な塹壕最大値・陣地構築速度・戦術・攻撃幅/防御/突破値再設計・空爆・指揮官スキルの全補正は別の工程に分ける。数値は暫定バランス値（後続PoCで検証）。

## リスクと検証
- 長期戦で塹壕+30%が攻勢停滞を過剰に増やす可能性がある。固定シード/同兵力比較と数百日試験で検証。
- 新たなセーブv20を導入するため、過去v19セーブのハッシュ不変、旧スキーマへのフィールド混入拒否、既存テストへの影響に注意する。
