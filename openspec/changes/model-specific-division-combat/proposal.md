# 師団に実配備した型番装備の戦闘性能を有効化する

## 背景と目的
v18までは型番別国家倉庫、訓練予約、師団保有を追跡できるが、装備カタログの攻撃/防御倍率は未使用。
また従来の銃器・火砲の研究技術は、装備の更新を待たずにすべての師団の戦闘力へ上乗せされる。

## 仕様（v18セーブ互換、戦闘式のみ）
- 配備済み師団の識別済み装備から `attackFactor`/`defenseFactor` を読み取る。
- 型番別装備数量は従来の師団保有量の内訳であり、戦闘では装備数を加算しない。
- カテゴリ内:  (未分類×1 + Σ型番数量×型番倍率) / 実保有数量。未分類は常に中立係数1。
- 部門構成: 攻撃 歩兵70%/砲兵30%、防御 歩兵80%/砲兵20%。カテゴリ不在なら存在するカテゴリのみ採用。
- 既存の装備充足率（sqrt）・組織・補給・地形・指揮官係数は変更せず、品質係数を乗算。
- `small-arms-standard` および装備カタログのモデル解禁研究について、当該カテゴリの直接戦闘加算を止める。
- ドクトリン・ドローン・電子戦のような装備以外の技術効果は残す。研究しても未生産の型番は装備された扱いにならない。
- 既存の戦闘トレース（unitCombatTrace）へ `equipmentModel` を表示（1のときは省略）。
- 計算は純関数で乱数を使わず、永続化ストアを追加しない。v18セーブ、v4〜v18移行を維持する。

## 受入条件
- 既存/未分類師団・1990小銃/2000火砲の倍率は1。
- 研究解禁しただけでは旧編制師団を強化せず、実配備後に攻撃/防御値が増える。
- 複数型番・未分類の混在で各数量による加重値が計算どおりになる。
- 装備損耗で品質係数が最新の残装備に追従する。
- 操作順・セーブ・ロード・決定論20tickと全既存CIに回帰がない。

## 非対象
- 強制装備交換・自動型番アップグレード、旧式装備回収、師団タイプ別の固有係数、AI装備最適化。
