# Combat system — bounded garrison reserve pool assignment (delta)

## ADDED Requirements

### Requirement: 未使用の安全な予備師団を含めた配置計画
駐屯作戦は、既存の防衛優先順位と移動可能性で選択した最大4目標について、選択済み師団に追加の未使用予備師団を最大8個含め、合法な陸路移動の総予想日数が短くなる場合のみ、選択する師団・目的地の対応を更新しなければならない（SHALL）。防衛する目標集合とその優先順を変更してはならない（SHALL NOT）。

#### Scenario: 未選択の予備師団が近い
- **WHEN** 初期計画で選ばれなかった配属師団が、対象防衛地点への総移動時間を短縮できる
- **THEN** 予備師団を選択済み師団と入れ替え、同じ地点をより短い総移動日数で守備する

#### Scenario: 新しい割当では改善できない
- **WHEN** 追加候補によって移動時間を短縮できない
- **THEN** 元の割当を維持する

### Requirement: 元の駐屯守備と手動命令の保護
追加の予備師団は、同じ駐屯作戦に所属し、戦闘中・手動固定・移動中・包囲中・前線配属中・撃破済み・非自国支配州にいる場合には選択してはならない（SHALL NOT）。既存の駐屯対象州を守備中の師団は、追加予備として引き抜いてはならない（SHALL NOT）。毎週最大4命令の上限と非敵対陸路検証を維持しなければならない（SHALL）。

#### Scenario: 重要港を守備中の予備師団
- **WHEN** 予備候補師団が既に別の駐屯対象州を守っている
- **THEN** 新しい配置最適化はその師団を候補にしない

#### Scenario: 手動固定・移動中・包囲中
- **WHEN** 未使用の配属師団が手動固定や移動中、包囲中である
- **THEN** その師団を追加の予備として採用しない

### Requirement: 有界探索と再現性
最適化は一度に最大4目標・8追加予備師団を扱い、追加の合法経路探索を最大44回まで、割当を最大11,880通りまでに制限しなければならない（SHALL）。同条件の複数候補は安定した師団IDと地理距離で決定論的に解決し、セーブ形式を変更してはならない（SHALL NOT）。

#### Scenario: 大量の余剰師団
- **WHEN** 未使用の配属師団が8個を超える
- **THEN** 有界の候補集合に絞り、命令上限を超えずに計画する

#### Scenario: セーブ復元後
- **WHEN** 同じWorldStateをセーブ復元し、駐屯計画を再計算する
- **THEN** 同じ予備候補・合法割当を再現する
