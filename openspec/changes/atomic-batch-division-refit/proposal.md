# 原子的な複数師団改編

## 背景と課題
既存の `refitUnit` は1師団ずつ操作するため、100師団規模の編成更新が煩雑である。
連続して命令する方式は、途中の装備在庫不足や占領発生時に一部師団だけが改編される。

## 決定
- 新しい `refitUnits` コマンドは1〜100個の異なる師団IDと、所有国の既存・不変の自由編成ID/改訂を受け取る。
- 存在・所有・戦闘/移動/包囲・支配州・既存編成・全資源を **適用前** に検証する。
- 資源は購入と余剰返却を全師団で集約し、差引負担を一度だけ検査する。
- 負傷・損耗は無償回復せず、既存の `refitUnit` と同じ式で師団能力を変更する。
- いずれかのエラー時はゲーム状態を部分変更しない。コマンドの監査記録は従来通り残す。
- 軍団カード内の複数師団選択から実行でき、購入・返却・差引を表示する。
- 現行セーブ構造・リプレイ・既存の単一師団コマンドを維持する。

## 非対象
装備型番別の生産ラインや備蓄、戦闘機/艦船の型式は #30 で別変更とする。
編成の自動アップグレードや部分成功も行わない。
