# 型番別の累計製造履歴（Phase 6C）

## 目的
型番別の現在庫へ移行する前に、実際の製造実績を型番と国家単位で追跡できる履歴を作る。

## 変更の契約
- ワールド状態に `modelProduction: {country, modelId, produced}[]` を追加。
- 国家ごとの `lines` 実日次生産時のみ型番別の累計数量に加算。
- 集約二財倉庫への日次入庫と同じ見積値を使用し、同じ出力を二度生産しない。
- `legacy` モードの生産、貿易、訓練、補充、損耗、イベント経由の在庫変化はこの累計製造に加算しない。
- レコード順序を国インデックス・型番IDで固定。状態ハッシュ・セーブv16へ含める。
- v4〜v15のセーブは従来のハッシュで完全性検証し、台帳を空配列へ移行する。
- v16では範囲外の国、未知型番、負数/NaN/無限値、重複国・型番のレコードを拒否。
- UIは「型番別の累計製造実績」であることを明記し、残現在庫と区別する。

## 明示的非スコープ
**累計製造量は型番別の現在庫ではない。** 型番別の消費・貿易・部隊保有数を追跡するには、
在庫・訓練予約・部隊配備・補充・損耗・型番交換のすべてを同一台帳で扱い、
旧二財在庫との保存則を検証する必要がある。

## 受入基準
- 初回起動・旧セーブでは製造履歴は空
- 生産モードが `lines` の場合のみ製造実績が増える
- 型番切替後も旧型番の製造実績を保持する
- v15からの移行、v16の不正台帳拒否、セーブ後の決定論的継続一致
