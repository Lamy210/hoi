# Combat system — garrison route estimated travel days (delta)

## ADDED Requirements

### Requirement: 移動時間を伴う陸路診断
陸路診断は、合法な陸路が見つかった場合に現在の移動条件と候補師団の速度を反映した予想移動日数を表示しなければならない（SHALL）。経路未発見・診断中断・作戦停止・敵占領のときには、推測による日数を表示してはならない（SHALL NOT）。

#### Scenario: 本土の合法陸路
- **WHEN** 自国師団から駐屯対象の陸路が見つかる
- **THEN** 移動システムで積算した日数を候補師団に付随して返す

#### Scenario: 陸路が存在しない
- **WHEN** 現在の通行条件で合法陸路が見つからない
- **THEN** 対象地点に到達不能と記し、予想日数を返さない

### Requirement: 診断結果の限界と状態保護
予想日数の計算は既存のオンデマンド陸路診断の探索回数上限を増やしてはならない（SHALL NOT）。初めて到達可能だった候補師団の所要日数であり、最短移動師団や週次AIの割当と同じになると保証してはならない（SHALL NOT）。診断前後でWorldStateと作戦の状態を変更してはならない（SHALL NOT）。

#### Scenario: 診断探索予算ゼロ
- **WHEN** 経路診断の探索予算がゼロ
- **THEN** 結果を未確認とし、予想日数を表示しない

#### Scenario: 週次AIの別割当
- **WHEN** 複数の候補師団が対象に到達可能で、週次AIが総移動日数を最適化する
- **THEN** 診断は最初に確認した候補の予想値であることを明示し、週次AIの実行結果と混同させない
