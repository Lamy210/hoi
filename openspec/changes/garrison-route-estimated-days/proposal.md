# 駐屯経路診断の予想移動日数表示

## Why
PR #95で駐屯AIが師団固有の移動速度を考慮し、複数地点の合計移動日数を最小化するようになった。一方、既存の陸路診断は目的地への経路の有無と経由州数だけを表示しており、配置の移動日数を判断できない。

## What Changes
- 既存の明示的な「陸路を診断」処理で、合法経路が見つかった候補師団について、`estimateGarrisonTravelDays(w,u,route)` を再利用し区間ごとの移動日数を積算する。
- 到達可能な場合に限り、診断結果へ任意の `estimatedDays` を追加し、画面上に小数1桁で表示する。
- 適法経路が存在しない、配属兵力不足、作戦停止、敵占領、検査上限に達した場合は予想日数を表示しない。
- 候補は従来どおり師団ID順に走査して最初に到達できるものを採用する。**最短候補を選んだことや実際の到着日、週次AIの最適化結果と一致することは保証しない**と明記する。
- UIスナップショット時には経路探索を増やさない。既存の手動診断回数制限最大64を変更しない。

## Safety and Compatibility
- WorldState、セーブ形式、駐屯命令、移動AI、診断の対象州と探索予算は変更しない。
- 予想値は天候・補給・装備など現在の移動条件に依存し、将来変動し得る。
- 既存の診断RPC結果へ後方互換性のある任意数値を追加するのみ。経路がない場合に数値を捏造しない。
- 処理は入力を読み取るのみ。 `hashWorld` 不変を統合テストで検証する。

## Verification
- 韓国本土への経路について、移動システムの積算日数との一致を確認する。
- 陸路が存在しない済州島・探索予算ゼロ時には `estimatedDays` が欠落することを検証する。
- Playwrightで既存の駐屯陸路診断から予想日数と制約説明を確認する。
