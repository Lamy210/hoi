# 複数軍・複数師団の編成移籍を最短操作に統合する（HOI4型UI Phase 1.5）

## 背景
軍集団・軍は作成できるが、複数軍を軍集団へ移籍するには従来は軍を1個ずつ選び、編集パネルで操作する必要がある。
また指揮系統ツリーの「Shiftで複数選択」は実際には単一トグルであり、範囲選択ではなかった。

## 仕様
- 陸軍管理画面の上部に、編集パネルの開閉とは独立した所属変更パネルを常時表示。
- **師団 → 軍**：地図・指揮系統・詳細一覧から既存の1〜256師団選択をそのまま使い、軍を指定して一括編入/編入解除。
- **軍 → 軍集団**：軍のチェックボックスによる複数選択、未所属軍の一括選択、フォーカス中軍集団の全軍選択、クリアを提供。
- 現在所属数→予定所属数/24師団または/5軍、移籍対象数、選択件数を表示。
- 既に同じ編成に属する師団・軍は定員の追加消費と見なさない。対象が全件同じ所属なら命令を無効化。
- **定員超過、存在しない所属先、空の選択、不正ID**をUIの純関数プレビューで判定。コマンドの適用時には既存の`assignArmy` / `assignArmyGroup`が改めて検証。全件反映/拒否。
- 検索フィルタを維持した指揮系統ツリーで、Ctrl/⌘=追加/解除、Shift=表示中のアンカー〜クリック先までの連続範囲追加。最大256師団。
- 「表示中を全選択」「表示中を選択に追加」「選択解除」でタッチ環境でも複数操作可能。検索後も選択状態は保持。
- UIのみ変更。軍集団・軍・師団の所有権とセーブv18、決定論、戦闘処理への変更はなし。

## 検証
- 一括で2軍→軍集団、解除、再編入、所属数の動的変化をPlaywrightで確認。
- Shift範囲選択→2師団を軍へ移籍→別の軍へ再移籍→選択クリアをE2Eで確認。
- 定員24師団・5軍を越える予定を正しく拒否、再所属分を差し引いて容量を予測するVitest。
- 他国所属・重複ID・不正IDのプレビュー拒否と、既存コマンドの原子的な拒否。
- 旧セーブのロード/12tickの決定論維持。TypeScript/ビルド/Playwright/OpenSpec全成功。

## 非対象
- マップ上ドラッグによる軍団移籍、軍集団横断の複数師団攻勢計画、将軍効果、戦域/HQ、定員超過の能力ペナルティ。
