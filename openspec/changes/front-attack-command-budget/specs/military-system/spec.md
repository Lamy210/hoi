# Military system — front AI command budgeting (delta)

## ADDED Requirements

### Requirement: 自動作戦の命令予算は有効な命令にのみ使う
戦線AIは、攻勢投入上限および週次命令数を、キューへ実際に登録した命令の件数に対してのみ消費しなければならない (SHALL)。手動固定、移動、包囲、戦闘中、組織率0の師団は攻勢命令候補から除外しなければならない (SHALL)。

#### Scenario: 先頭の師団が手動固定中
- **WHEN** 攻勢の投入上限が1で、IDの小さい師団が手動固定され、後続に攻撃可能な師団が存在する
- **THEN** 固定師団へは命令せず、有効な後続師団の命令を1件キューに登録する

#### Scenario: 同日に既存のfrontMoveがある
- **WHEN** 1師団に対するfrontMoveがすでにキューにあり、別の有効師団が存在する
- **THEN** 重複命令は増やさず、すでに発行済みという理由で他の師団への命令枠を消費しない

#### Scenario: 発行後の手動介入
- **WHEN** AIが命令をキューに登録した後、適用前にプレイヤーが当該師団を手動固定する
- **THEN** キューにある旧命令は検証で拒否され、プレイヤーの固定状態と既存経路を優先する

### Requirement: 戦線作戦の再現性
同じseed、状態、コマンド順で戦線の選択とキューに登録する命令列が一致しなければならない (SHALL)。保存データのスキーマを変更してはならない (SHALL NOT)。

#### Scenario: 同一状態からの命令列再生成
- **WHEN** 同じseed・ワールド状態・戦線・師団編成から週次戦線AIを再実行する
- **THEN** 生成されるfrontMoveの師団IDとターゲット列が同じ順序で一致し、セーブスキーマは変更しない
