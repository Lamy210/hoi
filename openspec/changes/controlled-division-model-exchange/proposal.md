# 師団への型番指定装備交換（Phase 6G）

## 目的
装備型番別の戦闘倍率を実際にプレイヤーが活用できるよう、既存師団に新型装備を再配備する。

## 仕様
- 新コマンド `exchangeUnitEquipment`: `unitId`, `fromModelId`（型番IDまたは `unclassified`）, `toModelId`, `quantity`。
- 国家倉庫の指定した新型装備を、師団が保有する同じ財種の旧型または未分類装備と1対1で交換。
- 物理装備は新たに生産・消費しない。国家倉庫の二財総数・師団保有二財総数は交換前後で同値。
- 型番別国家倉庫と師団の配備記録を同時に更新。交換元の旧式型番は元の型番で倉庫に返却し、未分類は未分類のまま返却。
- 型番IDの有効性、財種の一致、師団所有権/所在/戦闘状態、型番在庫、交換元の型番数量、数量（整数1〜10万）を検証。
- 戦闘・移動・包囲中の師団、敵支配州の師団、在庫不足は原子的に拒否。
- 研究未完了の型番も、実際に倉庫に保有していれば交換できる（貿易による入手を想定）。生産開始の研究制限とは独立。
- 軍編成パネルで対象師団1個、交換先モデル、交換元、数量を指定。要求中は二重送信を防止。
- v18セーブ・状態ハッシュ・旧セーブ互換はそのまま。コマンドジャーナルを使用し決定論を維持。

## 受入条件
- 未分類→新型交換で国家・師団の装備総量が増減せず、型番内訳のみ移動
- 旧型→新型交換で旧型が倉庫に返却され、戦闘倍率が実際の装備型番に追従
- 不正要求・在庫不足・他国部隊・戦闘中の要求は副作用なく拒否
- セーブ/ロード後20tickの決定論・画面と既存CIが成功

## 非対象
- 複数師団の一括装備交換、自動アップグレード、製造回収率、改修費用と工数、廃棄。
