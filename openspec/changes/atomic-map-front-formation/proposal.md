# 地図で戦線作成と師団編入を1操作に統合

## Why
戦線の地図ドラフトは前回実装したが、軍・軍集団や選択師団を割り当てるには作成確定後に別の戦線パネルを開く必要がある。作成と編入が別コマンドだと一方だけ成功し得る。

## Scope
- 既存 `createFront` にオプション `units` を追加。全IDの重複、所有者、存命、上限256を先に検証し、1コマンドで戦線を作成・編入する。
- 新規作成+編入では平時と戦時の両方で手動固定状態を保持し、既存の明示編入コマンドの挙動は変更しない。
- 地図戦線指定画面に、編入なし、選択師団、軍未所属師団、軍、軍集団を選べるセレクタを追加。現在既存戦線に紐づく師団は除外して警告を表示する。
- 0件、256件超過、保留命令中の誤確定を防止。作成前に件数と手動固定数を表示する。
- 既存のFront、Unit、セーブスキーマv18、戦線AI、地図描画処理を再利用し、永続化フィールドは追加しない。

## Non-Goals
軍集団を複数戦線に自動分配する仕組み、UIから既存戦線に割当済み部隊を強制移籍する仕組み、作戦を日時指定して自動開始する仕組み。
