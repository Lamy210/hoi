## ADDED Requirements

### Requirement: 地図から戦線作成と軍・軍集団を一括編入
地図の戦線ドラフトには、編入なし・選択師団・軍未所属師団・軍・軍集団を指定するUIがなければならない（SHALL）。指定州と対象師団を1コマンドでまとめて確定し、戦線だけが作成される部分的失敗を許してはならない（SHALL NOT）。

#### Scenario: 平時に軍を同時に編入
- **WHEN** プレイヤーが戦線州と所有する軍・軍集団を選んで作成する
- **THEN** 既存の戦線と手動固定を維持しながら、未編入師団を新しい戦線にまとめて割り当てる

#### Scenario: 不正な師団が混じっている
- **WHEN** 編入対象に重複・敵国師団・破壊済み師団または257件以上が含まれる
- **THEN** 戦線作成も編入も拒否し、frontIdカウンタも変更しない

### Requirement: 既存編入に影響しない下位互換性
`createFront`の`units`が省略された場合は以前と同じ戦線のみを作成し、`assignToFront`の現在の動作やセーブ形式を変更してはならない（SHALL NOT）。

#### Scenario: 従来の戦線のみ作成
- **WHEN** プレイヤーが地図で部隊指定なしの戦線を作る
- **THEN** 初期状態は従来どおりで、師団は自動で移籍しない
