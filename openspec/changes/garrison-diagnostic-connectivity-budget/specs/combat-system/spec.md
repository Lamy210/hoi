# Combat system — garrison route diagnostics connectivity budget (delta)

## ADDED Requirements

### Requirement: 不可能な陸路は診断A*予算を消費せずに報告する
プレイヤーが明示的に実行する駐屯陸路診断では、駐屯計画と同じ現在の通行許可判定による連結成分の事前検査を使用し、合法陸路が存在しないと確定できる師団と目標の組み合わせではA*探索を行ってはならない（SHALL NOT）。実際のA*呼出数は指定予算以下でなければならない（SHALL）。

#### Scenario: 本土と離島を同時に診断
- **WHEN** 陸路診断で本土への経路探索に予算の1回を使い、別の指定防衛地点が孤立した離島である
- **THEN** 本土の合法経路を報告し、離島はA*を追加実行せず「陸路なし」と報告する

#### Scenario: 孤立した出発州に複数師団
- **WHEN** 指定防衛地点へ到達できない離島に複数の配属師団がいる
- **THEN** 全師団の到達不能をA*呼び出し0回で判定し「陸路なし」と報告する

### Requirement: 明示的な予算ゼロと未確認を区別する
`maxPathChecks=0` が指定された場合、診断はA*を実行してはならず（SHALL NOT）、未防衛で候補師団が存在する対象については連結性事前判定から「陸路なし」を推定せず「未確認」と報告しなければならない（SHALL）。A*の予算が尽きても未知の候補が残る場合は「未確認」を維持しなければならない（SHALL）。

#### Scenario: 予算ゼロ
- **WHEN** 接続可能な本土と接続不能な離島の2地点に対して診断予算0回で実行する
- **THEN** 両方とも「未確認」と表示し、診断のtruncatedをtrueとする

### Requirement: 診断結果の一貫性と非破壊
陸路接続があり得る場合には既存のA*と師団別ETAを使用し、候補師団の所有権・指揮権・最後の現地守備隊保護・優先順位の条件を維持しなければならない（SHALL）。同一診断実行内で同じ出発州・目標のA*結果を再利用してよいが、診断はWorldStateを変更してはならない（SHALL NOT）。

#### Scenario: 到達可能な港への経路
- **WHEN** 所属師団から同国の港湾へ合法陸路が存在する
- **THEN** 実際のA*が返した経路に基づいて候補師団・hop数・予想移動日数を報告する

#### Scenario: 診断の反復
- **WHEN** 同じWorldStateで診断を繰り返す
- **THEN** 同じ結果を返し、WorldStateのハッシュを変更しない
