# Combat system — stationed guards versus incoming garrison reinforcements (delta)

## ADDED Requirements

### Requirement: 現地にいる最後の駐屯師団を到着まで保持する
自国支配の駐屯目標から師団を再配置するとき、その地点に別の生存した配属師団が実際に駐留していなければ移動させてはならない（SHALL NOT）。到着予定の移動中師団だけを理由として、現地にいる最後の守備師団を出発させてはならない（SHALL NOT）。

#### Scenario: 増援が移動途中
- **WHEN** 駐屯目標に現地守備師団が1個しかおらず、別の配属師団がそこへ移動中である
- **THEN** その1個の現地守備師団は、プランナーでもコマンド適用時でも移動できない

#### Scenario: 増援が到着した後
- **WHEN** 増援師団が駐屯目標へ到着し、そこに未移動の生存配属師団が2個いる
- **THEN** 1個の師団は別の自国支配の指定防衛地点へ合法な陸路で移動できる

### Requirement: 将来のカバレッジと現地守備人数の分離
駐屯AIは、到着予定の師団を含む目標への割当を把握しつつ、駐屯地点からの出発可否には現地にいる未移動の守備師団数を用いなければならない（SHALL）。作戦の目標選択、週4命令上限、既存の公開命令とセーブスキーマを変更してはならない（SHALL NOT）。

#### Scenario: 新規目標の選択
- **WHEN** ある指定防衛地点には増援の到着予定がある
- **THEN** 予定カバレッジは維持し、同じ目標へ不要な追加の移動命令を出さない

#### Scenario: 命令を続けて適用
- **WHEN** 同じ目標を守る師団に連続して再配置命令が適用される
- **THEN** 最後の現地守備師団だけが残った後の移動命令を拒否する
