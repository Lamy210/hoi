# 生産ライン別の日産予測を表示

## 背景
実生産の `lines` モードを有効化しても、プレイヤーは総量しか把握できなかった。

## 仕様
- 工場割当、製造倍率、効率、国の法律/技術/難易度補正を共通の純関数で計算し、型番ごとの日産見込みを返す
- 予測の総和は実生産モードにおける歩兵装備/火砲の日次増分と一致する
- 休止、割当0、未研究の型番は生産見込み0。予測参照では状態を書き換えない
- 既存の生産ライン編集画面に型番ごとの日産数を表示（旧モードでは計画予測、linesモードでは実生産予定値）
- 国家概要の旧配分率スライダーをlinesモードで無効化
- 型番別倉庫・配備は変更しない
