## ADDED Requirements

### Requirement: 検証済み静的成果物の公開
mainから生成した公開用distのみをGitHub Pagesへ配信しなければならない（SHALL）。型検査・単体/統合テスト・ビルド・公開用ブラウザテスト・本Changeのstrict検証が失敗した場合は公開してはならない（SHALL NOT）。

#### Scenario: 検証の失敗
- **WHEN** 公開前の検証が失敗する
- **THEN** デプロイジョブは実行されず、既存公開版を維持する

### Requirement: サブパス上でのプレイ
公開用ビルドはリポジトリのサブパス /hoi/ でシナリオ読込・国家選択・地図表示・時間進行を提供しなければならない（SHALL）。

#### Scenario: 初回ゲーム開始
- **WHEN** 公開用ビルドを /hoi/ で開き日本を選択する
- **THEN** 地図が表示され、速度操作により日付が進む

### Requirement: 公開用デバッグ境界
公開用ビルドはクエリ文字列のみでE2E内部操作フックを有効にしてはならない（SHALL NOT）。

#### Scenario: E2Eクエリ指定
- **WHEN** 公開用ビルドに ?e2e=1 を指定する
- **THEN** window.__orbis は公開されない

### Requirement: 公開状態の確認と復旧
運用者は公開コミットとActionsの結果を追跡し、失敗時には最後の正常版へrevertして再検証・再公開できなければならない（SHALL）。セーブの互換性を確認せずに旧版への復元可能性を保証してはならない（SHALL NOT）。

#### Scenario: 公開後の不具合
- **WHEN** 公開版に重大な不具合が発見される
- **THEN** 運用者はコミットを特定し、セーブ互換性を確認の上でrevertを実行できる
