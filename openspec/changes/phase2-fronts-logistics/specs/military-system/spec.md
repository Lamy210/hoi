## MODIFIED Requirements

### Requirement: 戦線指示と優先規則

military-systemは戦線（Front）への師団割当とスタンス指示（防衛/攻勢/撤退）を提供し（SHALL）、明示された個別命令は戦線AIによる再配置を上書きしなければならない（SHALL）。戦線は「対象国・プロヴィンス集合・スタンス・割当師団・攻勢計画（目標プロヴィンス群＋投入上限）」を持ち、戦線AIの命令発行はコマンド経由で行われなければならない（SHALL）。プレイヤーの戦線とAIの戦線には同一の割当ロジックが適用されなければならない（SHALL）。

#### Scenario: 明示命令の保護
- **WHEN** 師団が明示移動命令を持つ状態で戦線AIが思考する
- **THEN** 戦線AIは該当師団の命令を変更しない

#### Scenario: 攻勢戦線の自動攻撃
- **WHEN** 攻勢スタンスの戦線に割当師団が存在し、目標州が前線から到達可能である
- **THEN** 戦線AIは投入上限内で師団を目標州へ移動させる

#### Scenario: 撤退スタンス
- **WHEN** 撤退スタンスの戦線に割当師団が存在する
- **THEN** 戦線AIは該当師団を補給効率が高い自国深部へ後退させる
