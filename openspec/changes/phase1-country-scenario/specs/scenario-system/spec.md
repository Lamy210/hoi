# Spec Delta

## ADDED Requirements

### Requirement: シナリオパックのロードフロー
パックロードは「manifest検証 → スキーマ → 参照整合 → checksum → 初期状態構築」の順序で行われ（SHALL）、違反は全件収集して一覧表示した上で拒否しなければならない（SHALL）。

#### Scenario: 全違反の一覧表示
- **WHEN** パックに3箇所の違反が含まれる
- **THEN** 3件すべてが一覧で表示される（最初の1件で中断しない）

### Requirement: 選択データAPI
シナリオ選択・国家選択画面のため、パック一覧（バージョン・出典・互換エンジン版）と国家一覧（色・首都・開始状況サマリ）の取得APIを提供しなければならない（SHALL）。

#### Scenario: パック一覧の表示
- **WHEN** タイトルからシナリオ選択を開く
- **THEN** 同梱パックの名前・バージョン・出典・互換性が表示される

### Requirement: 現代東アジアパックの同梱
5国家（日・韓・北・中・露極東）・約120プロヴィンス・World Bank 2023統計（quality_flag=real）・SOURCES.json（完成済み帰属文）を含むパックを同梱しなければならない（SHALL）。

#### Scenario: MVPパックのロード
- **WHEN** 現代東アジアパックを選択してロードする
- **THEN** 5国家・約120州が検証を通って初期化される
