# Military system — defense and counteroffensive

## ADDED Requirements

### Requirement: 戦線防衛の増援
防衛スタンスは攻撃命令を出さず、敵戦力が強い戦線州へ移動可能な予備師団を増援できなければならない (SHALL)。別の接敵州の最後の守備師団を引き抜いてはならない (SHALL NOT)。

#### Scenario: 敵の攻勢が大きい州
- **WHEN** 敵戦力の圧力が当該州の防衛戦力を超え、後方に健康な師団がいる
- **THEN** 戦線AIは予備師団へその州への合法な移動命令を登録する

#### Scenario: 手動命令を優先
- **WHEN** 増援候補が手動固定・移動中・戦闘中または包囲中
- **THEN** その師団には自動増援を命令しない

### Requirement: 反撃スタンスと限定奪還
反撃スタンスは自国領有州の奪還を目的とし、組織率・戦力比・戦線の投入上限を確認して攻勢を行わなければならない (SHALL)。敵国本来の領有州へ防衛目的だけで進撃してはならない (SHALL NOT)。

#### Scenario: 奪われた旧戦線州の奪還
- **WHEN** 元の戦線州が奪われ、その隣の味方州に再編済みの所属師団がいる
- **THEN** 実効戦線を後方に再構築し、兵力比1.5以上で奪還命令を登録できる

#### Scenario: 組織再編中
- **WHEN** 反撃候補の組織率が75未満
- **THEN** 反撃命令は発行せず、既存の停止・手動優先と同じ制限を維持する

### Requirement: 自動再攻撃は再編完了後のみ
自動攻勢は組織率60以上の師団のみで新規命令を組み立て、コマンド適用時にも同条件を再検証しなければならない (SHALL)。手動攻撃を制限してはならない (SHALL NOT)。

#### Scenario: 退却直後の再出撃
- **WHEN** 師団が撤退から回復中で組織率60未満
- **THEN** 自動攻勢の新規命令は発行しない

#### Scenario: 命令後の消耗
- **WHEN** AIが命令を予約した後、適用前に組織率が閾値未満になる
- **THEN** 古い命令は拒否され、師団の経路を変更しない
