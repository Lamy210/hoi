# Combat system — legal retreat

## ADDED Requirements

### Requirement: 撤退先は合法で安全な隣接味方州
戦闘で退却する師団は、隣接した**自軍支配**の陸上州のみを撤退候補にできなければならない (SHALL)。他国への通行許可を持たない中立地、海峡、敵部隊と交戦中の州には撤退してはならない (SHALL NOT)。

#### Scenario: 味方支配州がある
- **WHEN** 撤退時に陸上で接する味方支配州が存在する
- **THEN** 補給状態と敵への露出度から決定論的に安全な候補を選ぶ

#### Scenario: 味方支配の退路がない
- **WHEN** 全ての隣接州が非友軍支配、海峡または敵部隊と交戦中
- **THEN** 移動せず既存の包囲処理へ遷移する
