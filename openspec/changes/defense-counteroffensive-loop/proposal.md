# 戦線の防衛増援・限定反撃と再編待ち

## 背景
占領地を自動的に塗り替える前進処理が実装された一方、戦線の防衛は空白州の補填だけで、敵の圧力に応じた予備師団の増援や、奪われた州の奪還はできない。自動攻勢が組織率1でも命令するため、撤退直後の師団が繰り返し戦闘に投入される。退却先も中立国州が許容されていた。

## 変更
- `hold` は従来どおり攻撃禁止で、敵の駐留戦力や進入経路から危険な前線へ、予備の健康な師団を移動させる。最後の1師団が守る別の前線は空にしない。
- `counterattack` を追加。防衛増援に加え、敵の支配下になった**元々の自国領有州**のみ、組織率75以上かつ実戦力比1.5以上で限定反撃する。停止中/手動固定/移動中/戦闘中の師団は変更しない。
- 自動的な通常攻勢は組織率60以上、予備の再配置は45以上を要件とする。手動の攻撃命令は従来どおり。
- 陥落した元の戦線州に隣接する味方州へ実効戦線を再構築する。別国境・海峡・無関係戦争へ拡張しない。
- 撤退先は隣接する自軍支配の陸上州に限定し、補給良好・敵の接近が少ない州を優先。選択不可なら包囲として既存処理に委ねる。
- 旧セーブv19を維持し、Front.stanceの文字列だけを追加。UI・AI・save validator・OpenSpec・テストを更新。

## 非目標
戦術カード、毎時戦闘フェーズ、戦車装甲貫徹、CAS/航空優勢、経時的塹壕構築、突破パラメータ、軍団/軍集団指揮官の全戦闘補正は別の独立したPoCとする。

## リスク/検証
AIと戦場の局所バランスが変わるため、同種・同数師団の固定シナリオ、撤退経路、講和・併合の整合、ロード再現を回帰検証する。長期プレイの勝率・戦線移動距離・戦争日数は後続のバランス調整で定量計測する。
