## ADDED Requirements

### Requirement: 平時の戦線作成と編入
プレイヤーは開戦前でも生存する敵予定国に対し、自国支配州を明示した戦線を作成できなければならない（SHALL）。平時に作成した戦線は停止状態となり、前線AIが移動・攻撃命令を送信してはならない（SHALL NOT）。平時の師団編入では手動固定を変更してはならない（SHALL NOT）。

#### Scenario: 平時の一括紐づけ
- **WHEN** プレイヤーが戦線を地図で作成して未所属師団・軍・軍集団を対象に編入する
- **THEN** 対象の自軍師団のみ一括編入し、既存の手動固定を保持する

#### Scenario: 開戦前の自動実行禁止
- **WHEN** 平時に攻勢スタンスと目標を保存して、その後開戦する
- **THEN** 戦線は明示的に再開されるまで一時停止を維持し、作戦命令を発行しない

### Requirement: マウスで引く攻勢予定線
プレイヤーは地図上で敵国支配州を横断するドラッグ軌跡を入力し、攻勢予定の目標州集合として保存できなければならない（SHALL）。予定線は実際の移動経路・勝利保証とは明確に区別しなければならない（SHALL）。

#### Scenario: 開戦前に攻勢線を描く
- **WHEN** プレイヤーが戦線を選択して敵国州を横切る線を描く
- **THEN** 通過した敵支配州を攻勢目標に保存し、破線の予定線を描画しても戦闘や移動は開始しない

### Requirement: 軍・軍集団からの簡単な紐づけ
戦線パネルは選択師団、軍、軍集団、未所属師団から編入対象を選べなければならない（SHALL）。戦時に`manualHold`を解除する場合は対象IDと状態に対応する明示確認が必要となる（SHALL）。

#### Scenario: 手動固定中の部隊を戦時に編入
- **WHEN** プレイヤーが手動固定師団を含む軍を戦時戦線へ割り当てようとする
- **THEN** 影響師団数を表示し、確認がない場合は割当ボタンを無効とする
