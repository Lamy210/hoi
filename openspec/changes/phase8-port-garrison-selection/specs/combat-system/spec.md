# Combat system — Phase8 catalog port garrison selection (delta)

## ADDED Requirements

### Requirement: 実在港の駐屯対象選択
プレイヤーは既存の防衛作戦画面から、検証済み港カタログに存在し、かつ現時点で自国が支配する港の州だけを駐屯対象ドラフトに一括追加できなければならない（SHALL）。沿岸だけの州を港として扱ってはならない（SHALL NOT）。

#### Scenario: 自国の登録済み港
- **WHEN** 自国が釜山と仁川を支配するカタログで港一括追加を選ぶ
- **THEN** 指定州に2港が加わり、同一州の重複はなく既存の手動指定州も残る

#### Scenario: 敵支配港・カタログ不在
- **WHEN** カタログが無いか、港の支配権が他国に移った
- **THEN** 対象外の州を追加せず、追加できる自国港がなければ操作を無効化する

### Requirement: 防衛対象ドラフトの上限・支配権検証
港の追加によって駐屯対象が64州を超える場合、追加の一部だけを適用してはならない（SHALL NOT）。ドラフトの州が自国支配から外れた場合、作戦作成前に支配権を再検証しなければならない（SHALL）。

#### Scenario: 64州を超える追加
- **WHEN** ドラフトが64地点あり、未追加の港が1地点ある
- **THEN** 一括追加は全件拒否され、既存のドラフトは維持される

#### Scenario: 選択後の支配権変化
- **WHEN** 防衛対象に追加した港が作戦発行前に敵国に占領された
- **THEN** 作戦作成ボタンは無効化され、再指定の案内を表示する
