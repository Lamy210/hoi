# Phase8 港湾防衛対象の一括選択

## Why
港湾カタログと駐屯作戦は実装済みだが、港だけを防衛地点として一括追加する導線がない。沿岸州と実在する港を取り違えず、手入力を減らす。

## What Changes
- 現在の検証済み `UiMeta.maritime.ports` の州番号を下部軍団ドックへ渡す。
- 自国が現時点で支配している港の州だけを、既存の駐屯防衛ドラフトへ重複なく昇順で追加する。
- 64州上限超過なら全件追加せず、既存の指定州も維持する。
- ドラフト作成後に州支配権が変化した場合、作戦作成ボタンを無効にして再選択を促す。
- カタログ不在時はボタンを無効にし、海岸線から港を生成しない。

## Capabilities
- Phase8Aの実在港を従来の `createGarrison` に接続する読み取り専用のUI補助機能。
- 港を守る実際の週次陸路移動は既存の駐屯エンジンで行う。

## Impact
- 変更範囲: `GameScreen` / `ArmyCommandDock` / UI純粋関数 / Vitest / Playwright。
- WorldState、駐屯コマンド契約、保存版、海上補給・上陸・航行は変更しない。
- 外部依存と追加の常駐ジョブなし。

## Risks
- 古いドラフトに敵支配州が含まれている可能性。作成ボタンで現行支配権を再確認し、サーバー側でも既存検証を継続する。
- 地点上限の無言切り捨ては禁止。上限超過は追加せず、UIから再選択できる状態にする。
