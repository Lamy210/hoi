# Military system — front deployment policies (delta)

## ADDED Requirements

### Requirement: 自動配置方式の選択
プレイヤーは任意の合法戦線に対して、均等・戦略・最短の3方式で、選択した師団を一括配置できなければならない (SHALL)。同一入力に対し師団ID昇順の決定論的な配置結果を返す。

#### Scenario: 均等配置
- **WHEN** 同じ州に2師団がいて複数の到達可能な戦線州が空いている
- **THEN** 均等配置は全師団を同じ州に積まず、空いている戦線州へ分散する

#### Scenario: 戦略配置
- **WHEN** 国境接触・補給・インフラに異なる重要度がある戦線に複数師団を配置する
- **THEN** 重要度と既存駐留数により対象州を選ぶ

#### Scenario: 最短移動
- **WHEN** 複数の合法な戦線州がある
- **THEN** 師団の出発位置に近い州を優先する

### Requirement: 安全な一括配置
一括配置は所有権、生存、状態、戦線の現行revision、経路を適用前に検証しなければならない (SHALL)。手動固定/移動/戦闘/包囲を上書きしてはならない (SHALL NOT)。

#### Scenario: 非所有または手動固定の師団を含む
- **WHEN** 選択の中に外国師団・手動固定師団・不正IDが1つでもある
- **THEN** 全件を拒否し、すべての師団の位置・経路・戦線所属を維持する

#### Scenario: 古い戦線revision
- **WHEN** 指揮UIのrevisionが現在の戦線と一致しない
- **THEN** コマンドを拒否し、移動や戦線割当を変更しない

#### Scenario: セーブ再生
- **WHEN** 有効な一括配置の後にセーブ・ロード・同じ日数のシミュレーションを再生する
- **THEN** 師団の戦線所属・移動経路・状態ハッシュが一致する
