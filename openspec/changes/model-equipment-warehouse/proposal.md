# 型番別国家倉庫・未分類装備（Phase 6D）

## 目的
装備の型番別残現在庫を初めて実装する。ただし軍需装備の正本は既存の歩兵装備と火砲の二財集約在庫のままとし、
型番別在庫はその **追加ではない、識別済みの内訳** として扱う。

## 前提・保存則
- 国/財種別ごとに `0 <= ΣmodelStock <= aggregateStock`（浮動小数の丸め許容差を除く）。
- `unclassified = aggregateStock - ΣmodelStock`。新規・旧セーブの初期装備は全量未分類。
- `lines` 生産時だけ新生産した型番数量を残現在庫へ計上。旧配分率生産は未分類。
- 型番倉庫と累計製造実績は別ストア。累計値が減ることはないが在庫数量は消費で減る。
- 装備消費ではまず未分類、その後型番ID昇順で型番別在庫を消費する。
- 貿易では売り手から消費した型番付きの装備を買い手の型番別在庫へ渡す。未分類は未分類のまま。
- 訓練予約・師団への装備引渡し・補充・再編によって国家倉庫を離れた装備は型番追跡を終了する。
- 訓練キャンセルや再編による師団からの返還装備は型番未分類へ戻す。部隊内の型番保持は後続実装。
- イベントは正または負の二財倉庫増減として共通ヘルパーを通す。

## セーブ・整合性
- v17セーブ `modelStock[]` に {country,modelId,quantity} を永続化。固定順と新しいハッシュ領域を使う。
- v4〜v16旧セーブは既存ハッシュで検証後、全型番別残在庫を空配列として復元する。
- v17ロード時は国範囲・型番・数量・重複・二財総在庫超過を検出して拒否する。
- モード切替でも過去の型番別現在庫は維持し、以後の旧配分産出は未分類として入庫。

## 非スコープ
この段階では師団内・訓練中の装備型番までは追跡しない。
型番別戦闘性能、師団編制ごとの実保有型番、被害配分、旧版倉庫の由来推定は実装しない。

## 検証
- 初期/旧セーブ全量未分類、ライブ生産で型番別入庫かつ総量不変
- 訓練・補充・再編・イベント・貿易による保存則とモデル別減算
- v16互換ハッシュ・不正型番/重複/過大残高拒否・セーブ後25日継続一致
- Playwright: 国家倉庫の型番別現在庫と未分類数量の表示
