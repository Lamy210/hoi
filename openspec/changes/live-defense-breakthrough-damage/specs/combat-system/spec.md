# Combat system — defensive capacity and breakthrough

## ADDED Requirements

### Requirement: 守備と攻勢では別の被害吸収能力を使う
戦闘に参加している師団は守備側の場合に防御（defense）、攻撃側の場合に突破（breakthrough）を用いて被害を軽減しなければならない（SHALL）。能力値は師団の編制・組織率・装備・補給・地形・準備状態で決定論的に変化しなければならない（SHALL）。

#### Scenario: 十分な塹壕を持つ守備師団
- **WHEN** 同一地形・装備・組織率の守備師団の塹壕を0から6に変更する
- **THEN** 防御能力が増え、同じ敵からの組織率と装備損耗が低下する

#### Scenario: 準備済みの攻撃師団
- **WHEN** 同一条件の攻撃師団の作戦準備を0から5に変更する
- **THEN** 突破能力が上がり、守備側からの反撃による損耗が減る

### Requirement: 防御・突破による被害倍率は有界
戦闘の被害倍率は0.70～1.10に収まり、防御能力が敵攻撃を超えても被害ゼロにしてはならない（SHALL）。非有限値・負の入力は拒否しなければならない（SHALL）。

#### Scenario: 過剰な防御力
- **WHEN** 防御能力が敵の攻撃ポイント以上になる
- **THEN** 被害倍率は0.70で止まり、被害はゼロにならない

#### Scenario: 防御能力ゼロ
- **WHEN** 装備・組織率が枯渇して防御能力がゼロになる
- **THEN** 被害倍率は1.10となる

### Requirement: 戦闘幅とリプレイの一貫性
被害圧力の分母は実際に戦闘に参加した師団数に限り、戦闘幅外の予備師団は被害を負担してはならない（SHALL NOT）。再生とセーブ復元後の戦闘損耗は決定論的に一致しなければならない（SHALL）。

#### Scenario: リプレイ
- **WHEN** 戦闘中の状態を保存してロードし、双方を同じ日数進める
- **THEN** 保存した戦闘状態を含む世界ハッシュが各Tickで一致する

### Requirement: 戦闘トレース
攻撃側は突破ポイント、守備側は防御ポイントを、通常の戦闘力係数と区別して画面の戦闘トレースに表示しなければならない（SHALL）。

#### Scenario: 師団の選択
- **WHEN** 師団の戦闘トレースを開く
- **THEN** 防御または突破能力値と被害倍率の計算式が確認できる
