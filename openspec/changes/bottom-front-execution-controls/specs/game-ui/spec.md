# Game UI — bottom battle plan execution

## ADDED Requirements

### Requirement: 戦線の攻勢実行と停止・再開
プレイヤーは下部の戦線操作バーから、交戦中の非停止戦線を攻勢に切り替え、停止・再開を操作できなければならない（SHALL）。平時には停止戦線を再開してはならない（SHALL NOT）。

#### Scenario: 平時の攻勢計画
- **WHEN** 平時に停止中の戦線に攻勢目標を指定した
- **THEN** 攻勢開始は無効であり、勝手に戦闘命令を実行しない

#### Scenario: 開戦後の計画実行
- **WHEN** 開戦後に戦線を再開して攻勢開始を押す
- **THEN** 既存`setFrontStance`コマンドを発行し、capを1以上として攻撃姿勢にする

#### Scenario: 防衛に戻す
- **WHEN** 攻勢中の戦線で防衛ボタンを押す
- **THEN** 既存のhold姿勢へ切り替える

### Requirement: 手動固定の解除と自動配置は別操作
下部指揮バーは手動固定中の師団を明示的に解除できなければならず、解除と移動命令を暗黙に同時実行してはならない（SHALL）。

#### Scenario: 自動戦線へ復帰
- **WHEN** 手動固定師団の解除ボタンを押す
- **THEN** 対象の手動固定のみ解除し、別操作で自動配置できる
