# Combat system — front reserve rotation

## ADDED Requirements

### Requirement: 組織率に応じた前線交代
戦闘参加候補のうち組織率65以上の師団を先に戦闘幅へ配置し、同じ組織率階層では前線優先度と師団IDの順序を維持しなければならない（SHALL）。組織率65未満の師団も戦闘幅が空いているなら参加できなければならない（SHALL）。

#### Scenario: 高優先度だが疲弊した師団と健康な予備師団
- **WHEN** 山岳戦闘幅80に同じ幅20の5師団がいるが、優先度9の師団が組織率40で残り4師団が100
- **THEN** 組織率100の4師団が参加し、疲弊した師団は予備へ回る

#### Scenario: すべての師団が疲弊
- **WHEN** 戦闘幅に候補師団が4師団以下しかおらず、全師団の組織率が65未満
- **THEN** 低組織率の師団も戦闘幅を埋める

### Requirement: 非交戦予備師団は同州で再編できる
戦闘参加者の判定は州単位ではなく、当日の戦闘幅参加師団IDによって区別しなければならない（SHALL）。非参加師団は実戦闘損耗を受けず、通常の非移動・非包囲時の組織率回復処理を受けられなければならない（SHALL）。

#### Scenario: 同一州の防衛予備
- **WHEN** 防衛中の州に幅外の予備師団が存在する
- **THEN** 予備師団の組織率は回復し、前線参加師団は戦闘損耗を受ける

### Requirement: 予備の兵員・装備補充は自国支配州に限定
戦闘中に非参加の予備師団へ補充を行う場合は、当該州が師団所属国の支配下であり、補給・物資・既存優先度制御を維持しなければならない（SHALL）。実戦闘参加者と敵支配州にいる予備には戦闘中補充を行ってはならない（SHALL NOT）。

#### Scenario: 自国支配州の非参加予備
- **WHEN** 非交戦予備師団が味方支配下の戦闘州で装備不足になっている
- **THEN** 既存の在庫と補充速度制限内で装備が補充される

### Requirement: 実戦闘とUIの表示を一致させる
戦闘幅UIの参加者・予備の予測は実戦闘の選抜関数を共有し、組織率65未満の予備を再編中として表示しなければならない（SHALL）。予測だけでWorldStateを変更してはならない（SHALL NOT）。

#### Scenario: 日次交代
- **WHEN** 予備師団が組織率65まで回復する
- **THEN** 前線投入優先度に従って次の戦闘へ再投入できる

### Requirement: 決定論と保存契約
前線交代は戦闘当日の一時的な参加者集合で解決し、新しい永続フィールドやセーブバージョン増分を必要としない（SHALL）。保存・復元後の同一入力・同一Tickは同じ世界ハッシュとなる（SHALL）。

#### Scenario: セーブからの戦闘再開
- **WHEN** 交戦中の世界を保存し読み込み直して双方を同じ日数進める
- **THEN** 日次の世界ハッシュが一致する
