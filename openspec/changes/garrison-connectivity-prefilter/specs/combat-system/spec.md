# Combat system — garrison route connectivity preflight (delta)

## ADDED Requirements

### Requirement: 明らかに不可能な陸路はA*を実行する前に除外する
駐屯の経路探索は、一回の計画で現在の通行権・交戦状態・州支配から通過可能州の連結成分を計算し、出発州と目標州が異なる成分に属する場合は実際のA*探索を実行せず到達不能と返さなければならない（SHALL）。連結性がある場合は従来と同じA*探索を実行しなければならない（SHALL）。

#### Scenario: 離島には陸路が存在しない
- **WHEN** 出発州と防衛目標が接続されない別の陸地成分にある
- **THEN** A*の実検索回数を増やさず、到達不能な結果をキャッシュする

#### Scenario: 通過可能な国内の州
- **WHEN** 出発州と目標州が合法な隣接経路で接続されている
- **THEN** 従来のA*と同じ経路を返す

### Requirement: 通過可否の同一規則を使用し偽陰性を防ぐ
連結性判定は元のA*と同じ通行可能性規則を使わなければならない（SHALL）。到着州への立入りが不許可なら到達不能としてよいが、通過不能な始点からは従来のA*が退出を許すため、始点だけを理由に到達不能としてはならない（SHALL NOT）。

#### Scenario: 通過不能な出発州
- **WHEN** 出発州が外国支配下にあるが、合法な隣接州へ移動できる
- **THEN** 連結性判定だけで拒否せず、元のA*で経路を検査する

#### Scenario: 支配権変更後に再計画
- **WHEN** 通過不能だった州の支配権が変更され、再び通過可能になる
- **THEN** 次の計画は以前の到達不能キャッシュに依存せず合法経路を再評価する

### Requirement: 検索省略の計測と決定論を維持する
経路要求数は、実際のA*探索回数、既存キャッシュヒット数、事前連結性判定による拒否数の合計と一致しなければならない（SHALL）。到達不能件数は事前拒否を含めるが、実際にA*を実行した回数と混同してはならない（SHALL NOT）。WorldState・保存形式・駐屯移動命令を変更してはならない（SHALL NOT）。

#### Scenario: 同じ孤立した目標を繰り返し検査
- **WHEN** 同一の到達不能ペアに2回の経路要求がある
- **THEN** 初回は事前除外1回、2回目はキャッシュヒット1回として記録する

#### Scenario: 大規模合成計測
- **WHEN** 256師団と64目標を含む積層配置・分散配置のベンチを実行する
- **THEN** 実検索と事前除外の件数をそれぞれ報告し、既存の計画結果と決定論を維持する
