## ADDED Requirements

### Requirement: 軍団バーと作戦描画
軍団/軍集団・師団の複数選択、地図上の作戦割当、移動・停止・実行/一時停止と自動復帰を通常UIで提供しなければならない（SHALL）。選択とパンを区別し、地図と一覧の選択状態を同期する。

#### Scenario: 軍団を選択して移動
- **WHEN** 軍団バーから複数師団を選択し合法な目的州を指定する
- **THEN** 全選択師団の経路・命令結果を同時に確認できる


### Requirement: 陸軍の兵力・装備・補給管理
師団一覧は現在地・所属・命令状態、人員/歩兵装備/火砲の現有・定数・不足量、組織率、実効補給効率を示さなければならない（SHALL）。軍団と軍集団の選択は所属師団を一括選択し、集計・地図・命令に同一のIDを使用する。現有量は内部値のまま集計してから表示丸めを行う。補給効率と実物流量を混同してはならない（SHALL NOT）。

#### Scenario: 軍団の装備不足
- **WHEN** 軍団内の師団2個に不足装備15と20が存在する
- **THEN** 軍団集計は35の不足を示し、各師団の所在と補給状態を別々に確認できる

#### Scenario: 所属変更と軍集団の選択
- **WHEN** 師団が別の軍団に編入され軍集団を選択する
- **THEN** 現在の所属を一度だけ集計し、同じ師団に重複命令を発行しない
