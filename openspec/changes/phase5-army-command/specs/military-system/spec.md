## MODIFIED Requirements

### Requirement: 戦線指示と優先規則
軍団・軍集団の下で師団を戦線・攻勢・防衛・撤退・集結作戦へ割り当てられなければならない（SHALL）。強制撤退/輸送拘束、明示命令/hold、作戦AIの順に優先し、明示命令完了後も自動復帰が指示されるまでは再配置しない。旧Frontは単一の作戦状態に移行する。

#### Scenario: 明示命令の保護
- **WHEN** 割当師団の手動移動が完了しhold状態で作戦AIが命令を発行する
- **THEN** 自動復帰指示まで移動しない

## ADDED Requirements

### Requirement: 陸軍指揮階層と一括命令
師団は最大1軍団、軍団は最大1軍集団に属し、複数選択による編入・移動・停止を所有権と容量検証の下で原子的に実行できなければならない（SHALL）。

#### Scenario: 不正師団を含む一括移動
- **WHEN** 自国師団2個と他国師団1個を含む一括命令を発行する
- **THEN** 全件拒否し、各師団の経路と所属は変化しない
