## ADDED Requirements

### Requirement: 整数工場割当とライン効率
各生産ラインは装備モデル、要求工場数、実割当、優先度、効率を保持しなければならない（SHALL）。実割当総数は国家の稼働軍需工場数以下とし、不足時は優先度とIDによる決定論的順序で縮退する。旧Phase2の比率設定は移行専用とする。

#### Scenario: 工場喪失
- **WHEN** 軍需工場が15から10へ減る
- **THEN** 実割当総数は10以下となり、優先度順に配分が維持される

### Requirement: 生産ラインの変更と端数
日産には工場数・装備基準出力・効率・法・技術を一元適用しなければならない（SHALL）。装備切替時に効率を所定規則で更新し、端数は旧装備に帰属したまま保持する。

#### Scenario: モデル切替
- **WHEN** 歩兵装備AからBへラインを切り替える
- **THEN** Aの端数をBへ変換せず、新しい効率でBを産出する
