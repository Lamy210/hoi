## ADDED Requirements

### Requirement: 編成改訂版と予約の永続化
テンプレート所有者・改訂版・予約資源・訓練状態・配備待ち・IDを保存し、旧v4/v5から検証付きで移行しなければならない（SHALL）。参照先の無い版、重複ID、予約矛盾を拒否する。

#### Scenario: 旧版を参照する部隊の復元
- **WHEN** 編成改訂後にセーブして復元する
- **THEN** 旧版部隊と新版募集の参照と予約資源が変化しない

### Requirement: 旧版実ファイルによる移行検証
旧版実装で生成した保存fixtureを旧検証器で検証してから移行しなければならない（SHALL）。旧版で保存された人員・装備・予約量・識別子を保ち、移行失敗時は現在の状態と元ファイルを維持する。

#### Scenario: 旧版のチェックサム不一致
- **WHEN** 旧版セーブの検証に失敗する
- **THEN** 新版への変換・保存の置換を行わない
