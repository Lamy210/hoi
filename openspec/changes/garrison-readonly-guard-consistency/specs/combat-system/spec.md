# Combat system — read-only garrison guard consistency (delta)

## ADDED Requirements

### Requirement: 駐屯陸路診断で現地守備師団の出発可能性を正確に判定する
駐屯作戦のオンデマンド陸路診断は、指定された駐屯地点を守る最後の現地師団を候補として表示してはならない（SHALL NOT）。別の師団が指定地点へ到着予定であっても、実際に到着するまでは現地守備人数へ算入してはならない（SHALL NOT）。到着後は現在の状態に従って候補を再評価しなければならない（SHALL）。

#### Scenario: 移動途中の増援と未防衛目標
- **WHEN** 最後の現地守備師団が守る州へ、別の配属師団が移動中で、他の未防衛目標がある
- **THEN** 未防衛目標について現地師団を移動候補にせず、合法な移動候補がなければ「移動可能な師団なし」とする

#### Scenario: 増援が到着した後
- **WHEN** 増援が駐屯州に実際に到着して、未移動の守備師団が2個となる
- **THEN** 同じ未防衛目標への陸路候補を報告できる

### Requirement: 駐屯カバレッジ表示は現在地と将来の到着を区別する
駐屯のスナップショット投影は、現地で停止中の師団数のみをもとに他の指定目標へ移動できるかを説明しなければならない（SHALL）。移動中の師団を出発可能な現地守備師団として数えてはならない（SHALL NOT）。既存の「防衛中」「移動中」の表示は保持しなければならない（SHALL）。

#### Scenario: 現地1師団と増援1師団
- **WHEN** 指定州に1師団が現地守備中で、別の1師団がそこへ移動中であり、他の指定州が未防衛である
- **THEN** 未防衛州の状態を「移動可能な師団なし」と報告する

#### Scenario: 現地2師団
- **WHEN** 増援が到着して2師団が現地守備中となる
- **THEN** 未防衛州を「命令待ち」と報告できる
