## ADDED Requirements

### Requirement: 地図上での戦線計画のドラフト
地図上で戦線計画を指定する専用モードを設けなければならない（SHALL）。プレイヤーは自国支配州のクリック・矩形ドラッグで対象州を選び、ゲーム状態を変えずに視覚プレビューを確認できなければならない（SHALL）。交戦中の敵国が存在し、有効な州が1件以上指定されている場合のみ作成できる（SHALL）。

#### Scenario: 交戦中に州を限定した戦線を作成
- **WHEN** プレイヤーが交戦相手を選び、地図で自国支配州2件を指定して確定する
- **THEN** 既存 `createFront` コマンドへ対象州IDのみ送信し、新戦線が通常の地図戦線レイヤーに表示される

#### Scenario: 作成を取り消す
- **WHEN** プレイヤーがドラフトの作成をキャンセルする
- **THEN** WorldStateと既存戦線・師団所属・手動優先状態は変化しない

### Requirement: 地図クリックによる攻勢目標
プレイヤーは既存戦線を選択し、その戦線の敵国支配州をクリックして攻勢目標を更新できなければならない（SHALL）。目標の追加・除外に対応し、既存の作戦スタンスと師団の手動優先状態を自動で変更してはならない（SHALL NOT）。

#### Scenario: 戦線を維持して敵国支配州を目標に追加
- **WHEN** プレイヤーが戦線を選び敵国支配州をクリックする
- **THEN** 既存スタンスを維持した `setFrontStance` の目標変更のみを送信する

### Requirement: 操作モードの排他性
戦線作成と攻勢目標モードは、既存の師団矩形選択・移動・攻撃と排他にしなければならない（SHALL）。右クリックによる師団移動の誤発令を防止しなければならない（SHALL）。

#### Scenario: 地図ドラフトでのマウス操作中に移動命令を誤発行しない
- **WHEN** プレイヤーが戦線指定モードで地図をドラッグまたは右クリックする
- **THEN** 師団の移動・攻撃命令は送信されず、確定前の戦線計画のみ更新される
