# 地図上の戦線州ドラフト・攻勢目標指定

## Why
Phase 5の createFront は `provinces` 引数に対応しているが、公開画面のFrontsPanelは交戦相手のみ指定して全戦線州を自動生成する。地図上の線を選んで軍を配置するHOI4型のワークフローが実行できない。目標もドロップダウンのみ。

## What Changes
- 地図に「戦線指定」と「攻勢目標」モードを追加し、師団の矩形選択・移動・攻撃と排他にする。
- 戦線州は自国支配州のみクリックでトグル、矩形ドラッグで置換、Shift/Ctrl/⌘で追加、Altで除外。敵国支配州をUIから送信しない。
- 戦線ドラフトはエンジンに書き込まず、別色で地図プレビューと選択州件数を表示する。手動確定でのみ既存 `createFront{enemy,provinces}` を送信する。
- 攻勢目標は既存戦線を選んで敵国支配州をクリック。通常クリックで置換、修飾キーで追加・除外。既存 `setFrontStance` の `stance` を変更しない。
- 支配国・交戦状態・保留コマンド・対象州重複・上限を発行直前に再確認。Workerも従来どおり検証する。
- 保存v18、シミュレーション、AI、軍団割当ロジックは変更しない。

## Non-Goals
実境界の線を自由曲線で編集すること、1クリックで戦線と師団割当を原子的に処理すること、未実装のOperationエンティティを追加することは別Changeとする。
