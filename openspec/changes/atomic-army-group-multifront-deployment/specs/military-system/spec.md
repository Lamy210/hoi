# Military system — atomic group multi-front deployment (delta)

## ADDED Requirements

### Requirement: 複数軍の複数戦線への経路展開
軍集団に所属する複数の軍は、それぞれ指定された戦線へ1つのコマンドで配置を開始できなければならない (SHALL)。既存の均等・戦略・最短方式を利用し、経路と各戦線のrevisionを適用前に検証しなければならない (SHALL)。

#### Scenario: 複数の合法な戦線
- **WHEN** 同一軍集団の2軍について移動可能な別戦線を指定する
- **THEN** 全師団の戦線所属と既存の移動経路形式が一括設定され、瞬間移動しない

#### Scenario: 同じ戦線を共有
- **WHEN** 同一軍集団の2軍が同じ戦線を均等配置で指定する
- **THEN** 各軍を別々に計画せず、師団集合をまとめて戦線州への分散を決定する

### Requirement: 原子性と手動命令の保護
移動経路・所有権・戦線世代・指揮階層・生存・駐屯排他をすべて検証するまでWorldStateを変更してはならない (SHALL NOT)。手動固定、移動、戦闘、包囲中の師団を含む場合は全件拒否しなければならない (SHALL)。

#### Scenario: 後続の戦線に合法な配置州がない
- **WHEN** 指定した複数戦線のうち1戦線で有効な配備州または経路が見つからない
- **THEN** それ以前に計画した軍も含めすべての師団の戦線所属と経路を維持する

#### Scenario: 手動固定中の師団が含まれる
- **WHEN** 指定した師団の一部が手動固定中
- **THEN** 他の合法な師団の移動も開始せず、全件拒否する

#### Scenario: 保存復元と決定論的再生
- **WHEN** 複数戦線への展開後にセーブ・ロードし、同じ日数進める
- **THEN** WorldStateのハッシュと師団の戦線所属・経路が一致する
