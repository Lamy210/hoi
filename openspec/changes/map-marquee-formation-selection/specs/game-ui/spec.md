# Spec Delta

## ADDED Requirements

### Requirement: 地図矩形選択とマウスによる複数師団の操作
プレイヤーは明示的な矩形選択モードで地図上をドラッグし、自国師団をまとめて選択できなければならない（SHALL）。通常ドラッグのパン操作と衝突してはならず（SHALL NOT）、Ctrl/⌘/Shiftで追加、Altで解除、通常は置換とする（SHALL）。師団の選択数が256件を超える操作は現在選択を保持して拒否しなければならない（SHALL）。

#### Scenario: 一括移動や停止のための師団選択
- **WHEN** 範囲選択モードで2つ以上の自軍師団マーカーを矩形で囲む
- **THEN** 該当師団が共通選択ストアに入り、同じ複数師団命令バーが使用可能になる

#### Scenario: 既存の地図パンと選択が衝突しない
- **WHEN** 矩形選択モードが無効のまま地図をドラッグする
- **THEN** 地図がパンし、選択範囲は描画されない

### Requirement: 地図マーカーおよび師団一覧の修飾キー複数選択
地図マーカーのCtrl/⌘クリックは師団の選択を追加または解除し、Shiftクリックは追加しなければならない（SHALL）。師団一覧でShiftクリックした場合は表示中の連続範囲を追加し、Ctrl/⌘クリックは個別トグルする（SHALL）。他国師団は対象に含めてはならない（SHALL NOT）。

#### Scenario: マウスによる軍団への一括編入
- **WHEN** 複数師団をShift範囲選択して軍への編入操作を行う
- **THEN** 既存の所有権・定員・命令検証に従い、選択した師団のみ編入する
