# Combat system — threat-aware garrison priorities (delta)

## ADDED Requirements

### Requirement: 駐屯AIの戦略的優先順位
駐屯作戦の未防衛対象は、敵と交戦中の隣接州数、自国首都、沿岸、インフラ、人口、州IDの順序で決定論的に評価されなければならない（SHALL）。敵支配州を守備対象としたまま敵領への移動を発行してはならない（SHALL NOT）。

#### Scenario: 交戦中の敵隣接州と首都
- **WHEN** 自国首都と交戦中の敵支配州に隣接する州が共に未防衛
- **THEN** 敵隣接州から先に移動経路を検討する

#### Scenario: 平時の首都と沿岸
- **WHEN** 敵隣接の脅威がない首都と沿岸州が未防衛
- **THEN** 首都を優先する

### Requirement: 元の安全性制約と説明可能性
駐屯優先順位は世界状態の派生値とし、セーブ形式を変更してはならない（SHALL NOT）。最後の守備師団・手動固定・戦闘中・移動中・包囲中・駐屯命令枠の既存制約を維持しなければならない（SHALL）。陸路診断画面は、現行順位と順位の主要因を示さなければならない（SHALL）。

#### Scenario: 最後の守備隊しかいない
- **WHEN** 高優先度の別地点が未防衛でも、担当師団が現在の守備地点の最後の1師団
- **THEN** その師団を引き抜かない

#### Scenario: 既存セーブの再ロード
- **WHEN** 駐屯作戦を保存・復元する
- **THEN** 同じ世界状態に基づき優先順位を再計算し、保存されていない派生データへ依存しない

#### Scenario: 沿岸と港
- **WHEN** 沿岸だが港湾カタログの登録を確認できない州がある
- **THEN** 沿岸という属性として評価し、港として扱ったことにはしない
