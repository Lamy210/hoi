# Combat system — catalogued port defense priorities (delta)

## ADDED Requirements

### Requirement: 実在港だけを駐屯優先度の根拠に使う
駐屯AIは、検証済みシナリオ港湾カタログに存在する港の収容力を自国支配下の防衛地点の優先度に反映しなければならない（SHALL）。海岸に接するだけの州を登録港とみなしてはならない（SHALL NOT）。

#### Scenario: 自国の2つの登録港
- **WHEN** 釜山と仁川が同じ交戦状況・首都条件で防衛対象に含まれる
- **THEN** 収容力110の釜山を収容力80の仁川より優先する

#### Scenario: 沿岸州だが港ではない
- **WHEN** 沿岸フラグが真でも、港湾カタログに存在しない州が防衛対象となる
- **THEN** その州の港容量は0であり、登録港として扱わない

#### Scenario: 首都・敵接触との比較
- **WHEN** 首都や敵に接する州が登録港と同時に防衛対象になる
- **THEN** 敵接触と首都を登録港容量より優先する

### Requirement: 港湾カタログの派生値とセーブ復元
港湾容量はパックから決定論的に構築し、セーブ形式へ新たなフィールドを保存してはならない（SHALL NOT）。既存セーブを復元するとき、同一パックから同じ港容量を再構築しなければならない（SHALL）。港情報がないパックでも動作しなければならない（SHALL）。

#### Scenario: セーブ復元
- **WHEN** 駐屯作戦のある世界をセーブして同じパックでロードする
- **THEN** 保存ハッシュを保ち、港容量と防衛優先順位が復元前と一致する

#### Scenario: 港データ不在
- **WHEN** maritime catalogがないパックを使う
- **THEN** 港容量は全州ゼロとし、従来の沿岸判定だけで防衛優先度を決める

#### Scenario: 陸路診断表示
- **WHEN** プレイヤーが登録港を含む駐屯作戦を診断する
- **THEN** 実在港の優先度と登録済み収容力を表示し、その値を補給能力とは断定しない
