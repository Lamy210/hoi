## MODIFIED Requirements

### Requirement: 師団作成の実消費
師団の作成は徴兵可能人力と装備財の実消費を要し（SHALL）、不足する場合作成されてはならない（SHALL NOT）。歩兵師団テンプレートの費用は「人力10,000・歩兵装備1,000・火砲200」とし、補充も同一財から行われなければならない（SHALL）。

#### Scenario: 人力不足の拒否
- **WHEN** 徴兵プールが師団1個分に満たない
- **THEN** 作成コマンドは却下され、理由がUIに表示される

#### Scenario: 火砲不足での作成却下
- **WHEN** 火砲在庫が200未満のとき師団作成を試みる
- **THEN** コマンドは却下され、在庫・師団数は不変である

## ADDED Requirements

### Requirement: 指揮官

military-systemは国ごとの指揮官（スキル1-5・特性: 攻撃/防御/兵站）を決定論的に生成し、師団への割当を提供しなければならない（SHALL）。割当された師団の戦闘力は `1 + skill×0.04` の係数を受け、特性（攻撃/防御）は対応する側に +0.06 を加えなければならない（SHALL）。指揮官の効果はトレース可能でなければならない（SHALL）。

#### Scenario: 指揮官割当の効果
- **WHEN** スキル4の攻撃特性指揮官を師団に割当てる
- **THEN** その師団の攻撃側戦闘力係数に 1+4×0.04+0.06 = 1.22 が適用される
