# 作戦指揮センターの対象絞り込みと命令差分プレビュー（Phase 1.6）

## Why
軍・軍集団の作戦指揮センターでは、所属する全師団へ命令が送られ、選択中・要注意・未配属だけに絞れない。また既存の `assignToFront` は `manualHold` を解除するため、意図せぬ自動作戦再開を起こし得る。

## What Changes
- 対象を「全師団」「要注意」「戦線未配属」「現在選択中」から選び、所属外の師団は必ず除く。
- 保留・再開・戦線割当・戦線解除について、現状との差分だけをID順で抽出し変更件数を可視化する。
- 既存戦線の再指定によって手動固定が解除される師団も変更対象に数え、解除が発生する場合は明示的なチェック確認を要求。
- 空対象、無変更、256件超、保留中コマンドは送信不可。最終的な所有権・交戦・命令妥当性は従来どおりエンジンで再検証する。

## Capabilities
- game-ui: 指揮系統と地図の選択状態を共用した安全な作戦命令UI。
- military-system: 状態投影のみ。コマンド／シミュレーション契約は変更しない。

## Impact
`formationOverview.ts`, `FormationCommandCenter.tsx`, `ArmyManagement.tsx`, `styles.css`, VitestとPlaywright。
セーブv18維持。Phase 2のBattlePlan・作戦線編集・自動戦線分配は対象外。
