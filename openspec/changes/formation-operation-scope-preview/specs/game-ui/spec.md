# Spec Delta

## ADDED Requirements

### Requirement: 指揮センター命令の対象範囲と差分プレビュー
軍集団・軍の指揮センターは、全所属・要注意・戦線未配属・UI選択済みの師団から対象を選べなければならない（SHALL）。所属外を除外し、状態を変える師団のみを安定したID順で命令に含め、変更件数を送信前に表示しなければならない（SHALL）。空対象・無変更・256件超・保留中は送信してはならない（SHALL NOT）。

#### Scenario: 一部選択の作戦保留
- **WHEN** プレイヤーが複数師団から選択中の師団だけを対象にして保留する
- **THEN** 当該軍・軍集団所属の未保留師団だけに命令が送信され、他の師団に影響しない

#### Scenario: 差分のない操作
- **WHEN** 対象全員が既に保留状態で保留を選ぶ
- **THEN** 操作は無効化され、命令キューが増えない

### Requirement: 戦線再割当による手動固定解除の確認
戦線割当が対象師団の手動固定を解除する場合、UIは件数と自動作戦再開を明示し、明示確認前の送信を無効化しなければならない（SHALL）。対象・戦線が変更された場合は確認を失効させる（SHALL）。

#### Scenario: 手動保留中の師団を戦線へ割り当てる
- **WHEN** 既に手動固定のある師団が対象に含まれ、戦線を指定する
- **THEN** 固定解除件数を示し、確認チェックが入るまで戦線割当ボタンは無効となる
