## MODIFIED Requirements

### Requirement: 講和の貢献度スコア

講和における領土要求の配分は戦争貢献度スコアに基づき（SHALL）、貢献度は戦闘ダメージ（戦力比配分）と占領（+15・首都+20）から決定論的に日次加算されなければならない（SHALL）。講和提案は領土要求リスト（demands）を伴い（SHALL）、占領現状（支配/領有の組み合わせ）に整合しない州を含む提案は検証で却下されなければならず（SHALL NOT）、講和会議UIに妥当性警告を表示しなければならない（SHALL）。AIの受諾判断は要求価値とwarScore・戦争期間から決定論的に行われ、decisionLogに記録されなければならない（SHALL）。

#### Scenario: 貢献度の配分

- **WHEN** 停戦に至り講和が行われる
- **THEN** 占領現状ラインが基準となり、貢献度と要求価値がAIの受諾判断に使われる

#### Scenario: 妥当性警告

- **WHEN** 占領していない州を講和条件に含める
- **THEN** 提案は却下され、講和会議UIに妥当性警告が表示される
