# Proposal

## Why
Phase 1の最後のChangeとして、エンジン・地図・軍事・AI・セーブをプレイヤーが操作できる形に統合する。「段階的開示」「トレースの開示」「多言語化」はUI仕様の基盤であり、ここで最初の形を作る。

## What Changes
- `src/ui/` にReactシェル（トップバー・左国家サマリ・右コンテキスト・警告フィード・ボトムモード切替）を実装する
- タイトル/シナリオ選択/国家選択の3画面を実装する
- 時間UI（停止/×1〜×8・日付・自動抑制警告の表示）とセーブ/ロード画面を実装する
- ja/en ローカライズ（ICU・Intl）・キーボードショートカット（Space/1-5/M/Esc/F等）を実装する
- 開発者モード（AI判断ログ閲覧）を開発者設定から有効化可能にする

## Capabilities
### Modified Capabilities
- `game-ui`: メイン画面・時間UI・国家概要・警告フィード・多言語・ショートカットの機能要件を追加

## Impact
- **対象Phase**: 1 の 7/7。完了で docs/16 のMVP受入判定が可能になる
- **リスク**: R-13（学習コスト）: 開示レベル0は「地図・時間・国家概要・軍事」のみ。トレースは選択対象のツールチップから常に使える
