# Spec Delta

## ADDED Requirements

### Requirement: メインゲーム画面の実装
メイン画面は世界地図を常駐レイヤーとし（SHALL）、トップバー（国家・資金・日付・時間操作）、左の国家サマリと警告フィード、右のコンテキストパネル、ボトムのモード切替を備えなければならない（SHALL）。

#### Scenario: 画面構成の確認
- **WHEN** ゲームを開始する
- **THEN** docs/11 §2のレイアウトで全領域が表示される

### Requirement: 時間UIの実装
時間UIは停止/×1〜×8の切替、日付表示、進行遅延警告の表示を提供し（SHALL）、開戦などの重要イベントで自動一時停止（設定で無効化可能）を行わなければならない（SHALL）。

#### Scenario: 自動一時停止
- **WHEN** AI国家が宣戦する（自動一時停止有効時）
- **THEN** 進行が一時停止し、警告がフィードに表示される

### Requirement: 国家概要パネルの最小実装
国家概要パネルは政体・国庫・安定度・支持率を表示し（SHALL）、各値のトレース展開を提供しなければならない（SHALL）。

#### Scenario: トレース展開
- **WHEN** 安定度の表示を展開する
- **THEN** エンジン由来のcontributorsが一覧表示される

### Requirement: 警告フィードの実装
警告フィードは優先度順に警告を表示し（SHALL）、クリックで対象（プロヴィンス・戦争・国家）へジャンプできなければならない（SHALL）。

#### Scenario: 補給警告のジャンプ
- **WHEN** 補給途絶警告をクリックする
- **THEN** 地図が該当プロヴィンスへ移動し、補給モードで強調表示される

### Requirement: ja/enローカライズの初期実装
UIの全文字列はja/enカタログから提供され（SHALL）、キー差分は存在してはならない（SHALL NOT）。数値と日付はIntlで整形される（SHALL）。

#### Scenario: 言語切替
- **WHEN** 設定で英語を選択する
- **THEN** 全表示が英語になり欠落キーは存在しない

### Requirement: キーボードショートカットの初期実装
一時停止（Space）・速度（1–5）・モード巡回（M）・セーブ（Ctrl+S）・検索（F）・閉じる（Esc）のショートカットを提供し（SHALL）、一覧をUI内で参照可能にしなければならない（SHALL）。

#### Scenario: ショートカット一覧
- **WHEN** ?キーを押す
- **THEN** ショートカット一覧が表示される
