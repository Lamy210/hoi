# Combat system — per-garrison-plan route lookup cache (delta)

## ADDED Requirements

### Requirement: 単一駐屯計画での重複陸路探索を省略する
駐屯AIは同一計画内の同じ出発州と防衛目標への合法陸路を再利用しなければならない（SHALL）。到達できない経路も再検索せずキャッシュしなければならない（SHALL）。初回候補選定と複数師団の割当最適化は同じキャッシュを共有しなければならない（SHALL）。

#### Scenario: 同一州に集結した3師団と2つの港
- **WHEN** 3師団が同じ州にいて、2つの港への初回選定と代替割当を比較する
- **THEN** 経路の要求を複数回行っても、同じ出発州・目的地の実際の合法陸路探索は一度だけになる

#### Scenario: 陸路が存在しない
- **WHEN** 同じ出発州から陸路不通の目標を繰り返し評価する
- **THEN** 到達不能という結果を再利用し、同じ経路探索を繰り返さない

### Requirement: 移動結果とWorldStateの再現性を保持する
経路のキャッシュは単一の計画関数の呼び出し内に閉じ、別TickのWorldStateや異なる支配権へ持ち越してはならない（SHALL NOT）。経路配列は参照を共有して呼出側から書き換えられてはならない（SHALL NOT）。経路が共通でも、移動時間は各師団の速度で個別に計算しなければならない（SHALL）。

#### Scenario: 別の計画が新しい合法経路を評価する
- **WHEN** ある計画が完了し、次の計画が開始される
- **THEN** 前回のキャッシュに依存せず、その時点での世界状態を再評価する

#### Scenario: セーブ復元後
- **WHEN** 同一世界状態をセーブして復元し、駐屯作戦を再評価・進行する
- **THEN** 同じ配置計画とWorldStateハッシュを再現し、セーブ形式を変更しない
