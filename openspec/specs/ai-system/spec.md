# ai-system 仕様

## Purpose
プレイヤー操作がない国家の自律行動を担う。責務を9モジュール（国家戦略・経済・外交・軍事戦略・戦術・生産・研究・建設・危機対応）に分離し、Utility AI＋ルール/ビヘイビアツリー＋影響力マップで構成する。難易度は判断能力の差で表現する。

## Scope
### 責務
- 週次の国家思考ループ（分散スケジューリング）
- 各モジュールの評価（utility）とコマンド発行
- 判断ログ（選択肢・スコア・理由）のリングバッファ記録と開発者モード閲覧API
- 難易度の適用（評価頻度・計画深さ・誤差注入確率。資源ボーナスはHard以上で±10%上限）
- 暴走防止（思考時間上限・同一コマンド連発のクールダウン）
- LLMは使用しない（実行時）。MOD制作補助の文章生成はゲーム外ツールに限定する。

### 非責務
- 状態の直接書き換え（全行動はコマンド経由、INV-3）
- Utility関数の係数値の固定埋め込み（シナリオ/MODで調整可能な設定値として持つ）
- プレイヤー国家の自動運営（委任機能はUI経由でai-systemのサブセットを利用、Phase 4）

## Data Model
- AiRuntime: `{country → {lastThinkTick, stance, decisionLog}}`
- Utility評価: `{options[], scores[], chosen, reasons[]}`
- 影響力マップ: 国境近接の軍事力集約（週次更新）

## State & Transitions
- 思考: `idle → thinking(country×module) → commandsIssued → logged`。国家ごとに独立・非同期なし（同tick内の固定順）。

## Calculation Rules
- Utility: `score = Σ(重み × 特徴量)`。特徴量は国庫・安定度・脅威認知（diplomacyの影響力マップ）・戦争状況等。
- 誤差注入: 評価値に `N(seed) × difficultyNoise` を加算（決定論的シード派生）。難易度でnoise/頻度/深さを変える。
- 計画深さ: 先読みtick数（難易度で1〜3週）。

## Invariants
- AI発行コマンドは全てプレイヤーと同一の検証を通る（違反時は却下・ログ記録）。
- 思考順序は国家ID順固定（決定論）。
- LLM API の実行時呼び出しは行わない。

## Use Cases
- 資源不足の国が経済AIで鉱山建設を優先 → コマンド発行 → 判断ログに「投入不足→稼働低下」と記録。
- 強国が弱小隣国を脅威でなく機会と評価（貢献度・CB有無でutility変動）し宣戦。

## Anomalies & Error Handling
- 思考時間上限（ティアSで1ms/国、ティアLで実測）超過はそのモジュールをスキップ（次週に繰延）。
- 同一コマンド連発検知（3連続同一却下コマンド）でモジュールを冷却。

## Dependencies
- 依存先: 全ドメイン（読み取り）、game-core（コマンド）。
- 依存元: game-ui（判断ログ閲覧）、bench（難易度検証）。

## Security & Performance
- 思考は週次×国家分散（250国は1tickあたり数国）。
- 外部API・ネットワーク不使用。

## Acceptance & Tests
- 同一シードでAI行動の再現（リプレイ一致）。
- 難易度差の比較シミュ（Easy/Hardの行動分布差の定量確認）。
- 暴走検知テスト（無限ループ・連発）。

## Requirements

### Requirement: コマンド経由のAI行動
AIは全ての行動をコマンドとして発行し（SHALL）、状態を直接書き換えてはならない（SHALL NOT）。発行コマンドはプレイヤーと同一の検証を通る。

#### Scenario: 不法コマンドの却下
- **WHEN** AIが合法性検証に失敗するコマンドを発行する
- **THEN** コマンドは却下され、判断ログに却下が記録される

### Requirement: 分散スケジューリング
AIの思考は国家間で時間分散されなければならず（SHALL）、250国家が同一tickに思考してはならない（SHALL NOT）。

#### Scenario: 250国家の分散
- **WHEN** 250国家が存在する
- **THEN** 各tickで思考するのは数国程度であり、全国家が週内に思考を完了する

### Requirement: 判断ログの記録
AIの各判断は「選択肢・スコア・理由」を判断ログとして記録し（SHALL）、開発者モードで閲覧できなければならない（SHALL）。

#### Scenario: 宣戦判断の閲覧
- **WHEN** 開発者モードでAI国家の宣戦判断を開く
- **THEN** utilityの選択肢別スコアと理由（脅威・CB・関係値）が表示される

### Requirement: 難易度の判断能力表現
難易度は評価頻度・計画深さ・誤差注入確率の3軸を主軸とし（SHALL）、資源ボーナスはHard以上でのみ、上限±10%まで許容する（SHALL）。ボーナスはUIで透明化しなければならない（SHALL）。

#### Scenario: 難易度ボーナスの透明化
- **WHEN** Hard難易度で遊ぶ
- **THEN** 適用中のボーナス（若有り）が設定画面で明示される

### Requirement: LLMの使用制限
ai-systemは実行時にLLM APIを呼び出してはならない（SHALL NOT）。文章生成等のLLM利用はゲーム外の制作ツールに限定し、その出力はデータとして取り込む（SHALL）。

#### Scenario: オフライン動作
- **WHEN** ネットワークを切断した状態でゲームを開始する
- **THEN** AIは全機能を正常に実行する
