# game-ui 仕様

## Purpose
世界地図を中心とした情報密度の高いUIを提供する。トレースによる計算根拠の開示、情報の段階的開示、ja/en多言語化、色覚多様性対応を要件に含む。

## Scope
### 責務
- 画面構成（docs/11 §1 の22画面）とレイアウト（地図常駐・パネルオーバレイ）
- 時間UI（停止/×1〜×8・日付・自動一時停止設定）
- トレースツールチップ（contributors の整形表示）
- 警告フィード（優先度順・既読管理）
- ja/en ローカライズ（ICU・Intl整形）と色覚多様性（Okabe-Ito＋パターン冗長化）
- キーボードショートカットとアクセシビリティ（ARIA・フォーカス）

### 非責務
- 数値の計算（全てエンジン由来値の表示のみ。UI側の独自計算は禁止）
- 状態変更（コマンド送信のみ）
- 地図描画の実装（world-map の抽象を利用）

## Data Model
- UI状態（Zustand）: `{selectedEntity, openPanels[], revealLevel, lang, settings}`
- i18nカタログ: `{key: ja/en}`。数値・日付は `Intl.NumberFormat/DateTimeFormat`。

## State & Transitions
- 開示レベル: `0(最小) → 1(経済解放) → 2(詳細)`。設定で全開示可。開示レベルはセーブに含める。

## Calculation Rules
- 表示値はエンジンのスナップショット＋オンデマンドトレースのみ。delta表示（前日比）は過去スナップショットとの差分。

## Invariants
- UIはコマンド経由でない状態変更を行わない（INV-3）。
- ハードコード文字列ゼロ（CI検査）。

## Use Cases
- プレイヤーが警告「補給途絶」をクリック → 対象プロヴィンスへジャンプ → トレース表示。
- 色覚設定で政治モードのパターン冗長化が有効になる。

## Anomalies & Error Handling
- エンジン拒否コマンドは「理由つきトースト」で表示（無音失敗の禁止）。
- Worker死活監視: 無応答30秒で復旧案内（ロード→再開）。

## Dependencies
- 依存先: world-map（描画抽象）、game-core（コマンド・スナップショット）。
- 依存元: なし（最上位）。

## Security & Performance
- 外部リソースの読込はシナリオパックとローカライズのみ（CSP準拠）。
- 地図は常時60fps目標（実測ゲート）。トレース要求はオンデマンド。

## Acceptance & Tests
- E2E: 開始→進行→セーブ→ロード→宣戦→占領の主要フロー。
- ローカライズ網羅テスト（ja/en のキー差分ゼロ）。
- コントラスト・パターン冗長化のチェックテスト。

## Requirements

### Requirement: 地図中心のメイン画面
メイン画面は世界地図を常駐レイヤーとし（SHALL）、パネルはオーバレイとして配置しなければならない（SHALL）。時間操作（停止/速度）は常時アクセス可能でなければならない（SHALL）。

#### Scenario: パネル表示中の時間操作
- **WHEN** 外交パネルを開いた状態で時間を進める
- **THEN** 進行が継続し、パネル内の情報は現在tickの値に追従する

### Requirement: トレースの開示
UIは任意の選択エンティティについて、エンジンから取得した計算根拠（contributors）を表示しなければならない（SHALL）。UIが独自に計算した値を根拠として提示してはならない（SHALL NOT）。

#### Scenario: 戦闘力の根拠
- **WHEN** 師団の戦闘力ツールチップを展開する
- **THEN** エンジン由来のcontributors（地形・補給・装備等）が表示される

### Requirement: 段階的開示
UIは情報の段階的開示（レベル0〜2・全開示設定）を実装しなければならず（SHALL）、未解放システムのパネルを既定では表示してはならない（SHALL NOT）。

#### Scenario: 初期開示
- **WHEN** Phase 1相当の開示レベルでゲームを開始する
- **THEN** 地図・時間・国家概要・軍事のみが表示される

### Requirement: 多言語化と色覚対応
UIは日本語・英語を完全に提供し（SHALL）、キー差分ゼロを維持しなければならない（SHALL）。また色に依存しない情報の冗長化（パターン・アイコン）を主要モードで提供しなければならない（SHALL）。

#### Scenario: 言語切替
- **WHEN** 設定で言語を英語に切り替える
- **THEN** 全表示が英語になり、欠落キーは存在しない

### Requirement: キーボードショートカット
主要操作（一時停止・速度・モード切替・セーブ等）はキーボードで完結し（SHALL）、ショートカット一覧がUI内で参照可能でなければならない（SHALL）。

#### Scenario: キーボードのみの開始
- **WHEN** キーボードのみで操作する
- **THEN** 開始→進行→セーブが完結する
